# 冷站工况拟合与案例标注

冷站入口位于项目的「计量与验证 → 中央冷站」。案例库位于独立后台 `/admin#evaluation`，仅管理员会话可访问；数据库管理同时可查看拟合和标注修订。

## 冷站数据怎么准备

上传同一设备、同一时刻对齐的 UTF-8 CSV：时间、电功率、冷量功率、蒸发器流量、回水温度、供水温度、冷凝器进水温度。选择原件列、单位、时区、设备和电表边界，明确水或载冷剂密度、比热、允许平衡误差及依据，再指定带时区的留出期起点。

- 电表边界分为单冷机、单机组及所属泵塔、全冷站。单机组电表不能当作整个多机冷站。
- `W`、`kW`、美制冷吨分别选择；文件列名不能代替单位依据。公开 Vanderbilt 历史 CSV 的 `Tons` 列已经转换成 **W**。
- 流量支持 m³/s、m³/h、L/s、美制加仑/分钟；温度支持 ℃、K、℉。当前要求全部温度列使用同一单位。
- 无时区时间必须明确固定 UTC 偏移；不自动猜夏令时。累计电表底数不能作为瞬时功率输入。
- 缺测、无效值、重复、乱序、停机零值和时间缺口逐项保留。不会插补或默乘 60 修正流量。

系统计算 `流量 × 密度 × 比热 × 供回水温差` 并核对冷量。有效工况按时间分为训练与留出；四参数非负功率模型仅在训练期拟合，留出期计算 NMBE、CVRMSE 并保留训练域外工况。不可辨识、时间错误或水侧失衡均保留阻断；少于40个训练/20个留出工况也不会复制样本凑数。该最小样本门槛不是统计充分性的证明。

输出是**有来源的工况拟合候选**，不是传感器校验证书、全年能耗校准或现场签发。系数没有自动写入 EnergyPlus。实际原生冷机曲线、流量分配、水力与控制参数校准还需继续开发及独立现场验证。

通过 API 可创建、读取记录和按100行分页核对审计表：

```text
POST /api/projects/{project_id}/calibrations
GET  /api/projects/{project_id}/calibrations
GET  /api/projects/{project_id}/calibrations/{calibration_id}
GET  /api/projects/{project_id}/calibrations/{calibration_id}/rows?page=1
```

项目归属及写请求 CSRF 与其他业务接口一致。原件和规则哈希变化后旧详情拒绝作为当前结果使用；历史记录保留。

## 案例库怎么用

每例保存来源 URL/SHA、项目组、建筑标识、来源性质、许可、训练权利依据、问题、来源答案和可复现上下文。标注输入 JSON 每批最多200例；导入始终为待复核状态。

管理员可通过、拒绝或纠正答案，记录依据和出处是否已核对。展开「补充训练准入资料」可补授权条款、来源性质、输入原件哈希及工具上下文；原始标签不变，新信息进入修订历史。导出保留原标签哈希、复核哈希和复核人。

训练/开发/留出按稳定项目组划分。**同一建筑的楼层、专业文件、模型版本必须放在同一项目组。** 系统可拦截相同输入哈希跨组，但无法自动识别改名后不同文件是否属于同一真实工程，分组仍需复核。

官方基准标签及其整个项目组禁止导出训练；训练导出还要求：训练分组、通过或纠正、出处核实、有明确训练权利依据、输入哈希与上下文齐全、输入没有跨项目组冲突。公开下载不自动意味着允许商业微调。导出仅生成本地带出处语料，不上传服务商、不启动训练。

API 位于 `/api/admin/evaluation`，包括分页案例、导入、复核、历史与受限导出。来源标签数量不记作真实工程执行次数。

## 目前是否需要微调

目前没有证据证明应先微调大模型。已发现的错误包括工具结果错归属、漏调用、CSV误用IFC工具及从少量样例推断全部问题；本轮首先通过具名上下文、执行检查、按原件格式在本机限制工具、失败反馈和完整分布数据修复。冷站单位/边界错误需要工程校验；模型权重训练不能补出缺失的流量单位或实测设备记录。

已整理1,026条作者问答为保护的评测集，另有四个实际设计项目的193条机器派生事实/源空间轮廓标签。后者包含源文件自身的拓扑错误，尚需复核及权利核实，不能当作人工确认的房间分割真值。当前可导出训练例为0，已训练大模型权重为0。

下一道门槛是按独立工程留出，对同题的基座、工具增强、检索增强分别评测，再判断剩余错误是否适合微调。残损扫描图还缺独立标注的图页/比例、墙线和门窗、遗漏空间、修复依据与像素级轮廓；中央系统还需可定位设备台账、拓扑、运行控制及独立实测量。仅增加同一模型的问答或楼层，不能证明这些覆盖已足够。

完整实测、失败和覆盖缺口见[本轮报告](benchmarks/2026-10-29-calibration-labels/README.md)。
