# 设备运行核查：限定闭环交付

2026-11-05。属于95+路线工作包3，仍为开发过程验收，非现场诊断认证。新增CSV原件上传→明确测点/时间/单位→规则筛查→异常行号/质量缺口→历史失效→JSON/HTML报告及Agent只读工具。范围、差值和变化率均有实际计算，没有模型生成的假告警或默认健康评分。

## 输入及计算边界

- UTF-8 CSV最大8 MiB、50,000样本、64列；最多20映射测点及30条规则。明确时间格式、偏移时钟或声明本地时钟、采样间隔及最大连续间隔。重复/倒序时间、列数不一致和损坏CSV拒绝。
- 支持摄氏/华氏/K、功率、压力、比例/百分比、转速、质量流量、体积流量及离散状态。规则和工况门槛使用显式归一单位，跨量纲差值拒绝。未知或无效值保持null。
- 范围外使用严格小于/大于；差值/变化率为绝对值且严格超过阈值。CSV十进制值转有理数，华氏换算采用 `(F-32)*5/9`，事件判断不经过二进制浮点。API数值阈值以已解析数值的十进制表示参与计算；JSON数值精度和浏览器数字输入精度仍有上限。
- 数值单元限128字符、40位有效数字、十进制指数±100；归一值绝对值≤1e12，低于绝对零度、比例不在0–1、非整数状态记为无效。超界编码不能耗尽无界整数资源。
- 持续时间只取首末异常样本跨度，不外推末点。缺测、未知工况、工况不适用或超过最大间隔切断事件；一阶变化率的首点和长间隔后点保持未知。事件仅证明采样规则触发，不证明样本间连续异常。
- 最多保存每规则前200事件、前100质量明细，另保留完整总数及截断标志；原件不截断。预览最多200点，不绘制误导性连续插值。汇总为样本均值，不是能耗积分。
- 项目声明、CSV、绑定证据、计算器版本及结果哈希可追溯；撤回、篡改或版本变化后结果隐藏，历史原记录不改写。所有路由沿用登录、项目归属和CSRF。Agent工具只读，不控制设备。

## 独立数据与交叉验证

来源：[OpenEI LBNL FCU数据](https://data.openei.org/submissions/5763)，DOI `10.25984/1881324`；[2022-08-01数据清单](https://data.openei.org/files/5763/Inventory%20of%20LBNL%20FDD%20Data%20Sets_FCU.pdf)；[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。数据由HVACSIM+生成，**仿真而非真实建筑实测**。温度为degF、功率W、阀位及指令ratio。时区未推断。

通过官方压缩包HTTP Range获取两个完整成员并读至EOF验证ZIP CRC，只保留各自首10,080行（2018-01-01至01-07，1分钟采样）。实际下载35,705,257字节；未下载整个530,633,129字节压缩包。第一次按清单文件名`Fault_free.csv`匹配失败保留原日志，检查归档目录后采用实际`FCU_FaultFree.csv`。供热阀卡闭文件在查看结果前按冬季窗口选择。

在执行结果分析前固定规则：供热指令≥0.2时，指令与反馈绝对差>0.1，观测跨度≥300秒，最大间隔90秒。它是审计启发式规则，**不是规范阈值或训练出的诊断器**。`scripts/verify_operations_reference.py`用单独CSV/Fraction分组算法交叉核对实际FastAPI上传/分析返回的行号、事件跨度和覆盖。

## 实际测试及性能

- 专项31项：缺测/NaN、时区相同瞬间、倒序、模糊日期、量纲/精度边界、工况排除、断点、范围/变化率、事件截断、报告转义、Agent只读/越权、CSRF、证据撤回及原件/记录/代码失效。
- 浏览器真实上传7行人工合成CSV、手工填表并保存；120秒门槛只生成第3–5行的1个事件，第7–8行60秒不计事件。68°F显示为20°C，100%显示为1 ratio。原件哈希保持一致。
- 计算器更新后旧记录显示stale且不显示旧数值；复制原输入、新建最终快照、HTML报告同源、规则切换隐藏字段禁用、更改测点后拒绝旧引用均实际操作。最终记录`operation_43d8406f69d64d3a830cca7b4372c3ca`。
- 精确数值版公开API单次分析约0.714/0.450秒（两切片），一次本机上限容量50,000行×20测点×30规则约10.614秒。非并发吞吐、非SLA、非长期稳定性证明。
- 完整回归和前端构建结果见同批证据索引。保留Starlette TestClient弃用提示及Three.js分块大小警告；没有据此宣称依赖或全局性能问题全部解决。
