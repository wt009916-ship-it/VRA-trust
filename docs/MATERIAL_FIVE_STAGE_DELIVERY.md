# 材料方案五阶段核算：限定任务交付

2026-11-08。基底为5209d744；当前批次独立于待授权的PR53/PR54发布。新增同源材料运输派生、五阶段共同边界/活动录入、阶段报告及证据绑定。属于原C01–C05/C08与H场景的限定补强，不能代表完整LCA规范、实楼核证、改造效果或碳资产认证。原八维评分本批不增加，95+尚未达到。

## 实际能力

- 两方案以同一IFC材料计量为数量来源。运段只能引用已纳入层，采购体积乘明确密度得到质量，再计算 `(采购质量×承运比例+附加包装质量)/1000×距离` 吨公里。多运段可分别记录；距离、承运比例、包装质量未知时不代填0。
- 两方案共同声明生产、运输、施工、运行、寿命末期的范围。运行年量按声明评估期线性累计；不是自动节能预测。排除阶段显示“未纳入”，纳入但无活动/无因子显示“资料不完整”，不能形成确定比较。
- 材料映射、运段、其他活动及排放因子可选择项目证据，保存修订快照。证据被拒绝或变化后当前结果撤下，原历史不改写。来源文字和待审证据仍是声明，不能自动升级为核证数据。
- 报告显示各阶段结果、运输换算、期间倍数、因子名称/发布方/版本/年份/地区/方法，JSON保留完整输入和回执。生产行按活动ID关联，避免追加运输后按位置错配生产碳。

运输计算形式参考[GHG Protocol Scope 3计算技术指南](https://ghgprotocol.org/sites/default/files/standards/Scope3_Calculation_Guidance_0.pdf)第61页公式4.6；第62页示例的2t×2000km×0.2=800kgCO₂e用于独立算术核对。该示例因子不是本项目可直接采用的实际运输因子，该企业Scope 3方法也不构成建筑LCA合规证明。

## 验收与失败保留

- 首轮相关后端100通过/5失败：其中四个新测试误用POST /review（真实接口为PATCH evidence），一个显示断言误把3000.0当作不同于3000。原日志保留。只修测试器，无计算代码变化；干净候选最终运输/五阶段专项18通过。不能把两轮数字相加冒充同次全量。
- 干净候选前端133通过、构建通过、专项Ruff与独立API导出通过。未混入停放catalog的6个前端测试。完整CI另核验，不拿以上专项冒充全量。
- 浏览器范围：由API先实际上传/解析公开IFC，随后浏览器选墙5903→重新计量→填写三层两方案→2个运段和6项活动→提交→打开报告。新表单并非仅脚本直接POST通过；本批也不冒充再次用浏览器上传原文件。
- 浏览器缺距离产生incomplete/null比较；排除运输但保留运段返回409。撤销实际选择的证据后，原已计算报告显示失效并撤下旧总量。
- 浏览器脚本首次用后缀_id同时命中运段ID和因子ID，提交前失败；改用行前缀并通过页面移除未完成行后重录，保留记录。不是产品计算通过证据。
- 390px报告无整页横溢出，宽表仅表内滚动；实际截图已审阅。表单也无整页横溢出，但长表单、字段繁多及英文错误信息仍影响舒适度，不据此给全局体验满分。
- 隔离服务已停止、18775端口释放、临时会话文件删除。原型18772和原业务数据未被本批修改。首次发布准备曾因误把受限端口枚举当成停服而中止；直接连接重新确认旧原型健康，未执行停服或替换。
