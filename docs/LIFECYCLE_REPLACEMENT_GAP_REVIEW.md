公开方法来源：RICS *Whole life carbon assessment for the built environment*, 2nd edition, version 3, August 2024，5.2.4，印刷页89–92附近。
[官方PDF](https://www.rics.org/content/dam/ricsglobal/documents/standards/Whole_life_carbon_assessment_PS_Sept23.pdf)

该方法将替换过程的相关排放纳入B4；寿命与评估期决定替换情景，次数取整数，末次替换还需考虑实际发生可能性。项目具体寿命依据优先，不能把示例寿命直接当项目实测值。此处不复制示例寿命表，不声称自动满足整套RICS或中国核算规范。

待实现的产品契约（以下为开发设计，非规范原文）：

1. 显式声明评估期、初次安装/剩余寿命、后续使用寿命、寿命来源与末次更换假设；不从材料名称猜寿命。
2. 输出逐次发生年份及次数，用离散事件独立复核；不在评估终点自动再安装一个无使用期的新构件。该端点规则须作为明确的计算情景口径，不宣传为通用强制规则。
3. 每次替换区分新件生产、运输、安装和旧件移除/处理；缺项与明确排除分开。不能只乘生产碳后宣称替换全阶段完整。
4. 与初始/最终处置、年度运行、已有人工整期活动分别列账；核对基准是否已经包含替换，无法证明时保留重复计数风险，不自动合并。
5. 原件、因子、项目面积/期间及寿命依据变化须使派生结果失效，旧账保留。比较方案需要相同功能单位和期间；不签发信用或认证。
6. 独立算例应覆盖整除/非整除评估期、寿命超过评估期、已有构件剩余寿命、零/负/极短寿命、缺因子、移除边界、单位与版本冲突；没有现场依据时保持声明情景。
