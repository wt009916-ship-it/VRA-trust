## 实际改动

最多三条结果和六个声明范围，保持原15事件、5模型响应上限。常规三结果加三目录为14事件，含末次来源检查。预检为所有操作预留容量；不足时明确失败。单条缺失、拒绝或读取错误不取消其余合法要求，缺失必须再次查询原编号。停止请求仍中断执行。控制流程事件明确标为controller，答案说明不将应用代执行包装为模型自主工具选择。`intent_verified=false`与自由问题完成度partial继续保留。

另修复造价与其他专业合并交付时缺少统一`record_id`导致的KeyError；只在多专业交付视图补充来源编号，不改造价数值、记录或旧历史。
