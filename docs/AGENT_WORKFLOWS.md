# 工程智能体与模型接入

智能体连接项目资料、工程工具和行动任务。它可以说明当前资料支持什么、调用工具核查、给出来源与补证顺序；正式计算与结论仍以工具结果为依据。

## 配置服务

管理员进入 `/admin#services` → 管理模型与 API 连接。选择与你的Key所属平台一致的预设，填写Key并启用，保存后测试。

|服务|完整Chat接口|对话/工具模型|视觉模型|
|---|---|---|---|
|腾讯TokenHub|`https://tokenhub.tencentmaas.com/v1/chat/completions`|`deepseek/deepseek-flash`|`deepseek/deepseek-flash`|
|DeepSeek官方|`https://api.deepseek.com/chat/completions`|`deepseek-flash`|`deepseek-flash`|

[腾讯模型列表](https://cloud.tencent.com/document/product/1823/130051)与[DeepSeek官方说明](https://api-docs.deepseek.com/quick_start/)核对于2026-10-28。模型能力与权限会变化，以服务商当前列表和实际测试为准。两个平台的Key和模型ID不能混用；401时核对平台、接口和Key。

Windows Key由当前系统账号DPAPI加密保存，页面不回显。更换服务地址时需要同时填写对应的新Key，防止把旧凭据发往其他服务。连接测试实际完成模型发起函数调用→返回测试结果→模型答复，工程工具执行数为0；这不等于项目所有智能体任务通过。

## 项目中使用

在项目概览输入任务，选择AI模型。也可选「计量与校准检查」「工程复核」「构件与设备来源」等任务类型。

- 「允许AI读取资料摘录」默认不选。开启后，本次任务才发送有限、带来源的文字摘录；不会上传原文件。视觉识别另外需要在建模导入中明确同意发送选定图页。
- 「允许计算」用于实际EnergyPlus等计算动作。现有结构化计划、来源、版本和计算准入仍有效。计量数据阅读不需要这个开关。
- 已执行的工具、模型请求、耗时、返回token用量、失败与策略版本写入任务历史。后台数据库可查询智能体任务、计量检查和误差比较。

### 推荐任务

|目的|可以输入|实际依据|
|---|---|---|
|残缺资料核对|“检索资料中的设备COP和运行时间，给出文件页码，列出尚需确认的信息。”|本地已解析且未拒绝的资料；摘录引用绑定原件哈希与人工校正版本|
|建模排障|“检查这一层的建模失败，列出对应房间、源构件和补证行动。”|模型、导入诊断、当前工程复核问题及构件清单|
|计量与校准准备|“检查电表缺测与时区，目前是否能比较，距离现场校准还缺什么？”|当前计量分析有效性、缺测、边界和来源；缺测不补零|
|构件与中央设备资料|“源IFC里有哪些机电/家具，哪些没有几何或不能进入热模型？”|已提取的源构件类别、失败数量、来源及失效状态|
|材料与改造方案|“按当前检测依据检查稀土材料，解释方案约束和下一步补证。”|材料登记、已运行研究及准入；不编造检测优势和造价|
|工程交接|“整理工程复核问题，按房间说明未解决项和下一步。”|当前版本问题与定位；处置仍由工程师记录|

## 当前实现与边界

新增工具为`measurement_audit`、`engineering_review`、`component_inventory`、`project_document_search`，连同既有工具共29项。任务中区分预设流程和模型自主调用，不能把预先读取工具算成模型自主规划。

资料搜索目前是本地词法检索，覆盖已解析活动证据，扫描预算400页，每次最多5条、每条750字符。人工校正与原文保留；原件变化、跨项目文件、已拒绝资料不作为当前有效摘录。引用ID核验只能确认该ID来自本次检索，不能自动证明每句话与原文完全一致。尚无通用向量语义检索、任意缺页恢复或工程师级文意审核。

发给模型的全楼几何和长列表有显式截断提示，完整工具依据保留在本地任务历史。单任务最多5轮模型交互，工具/时间/并发预算继续限制执行；外部网络中断或主机休眠影响完成率和耗时。供应商失效时保存工具结果与失败，不能显示AI已完成。

## 这次“训练”做了什么

本轮是**智能体策略调优、工具集成与真实任务评测**：修改版本化系统策略，依据开发任务错误修订，再运行另一组建筑留出任务。没有训练或微调DeepSeek模型权重，也没有把API调用成功当成工程准确率。

开发阶段发现并记录了平台Key错配、网络失败、将未插补混称缺测、将匿名标签误当月份矛盾等问题。最终留出集10栋完成工具调用且读数与原件验收一致；仍需审查模型说明，不能由这次结果声称任意建筑/任意任务可靠。

[真实调用、失败、token与引用验收](benchmarks/2026-10-29-agent/README.md)。后续微调应先积累由工程师确认的任务/工具轨迹/错误修正与评价标准，保留独立留出项目，再决定是否需要模型训练。
