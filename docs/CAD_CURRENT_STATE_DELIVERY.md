# CAD 当前状态与失效撤下交付

本批修复 IFCU-06：原件损坏后，后端已经返回 stale/null，但普通 CAD 构件明细仍显示旧体积。新增项目授权及 CSRF 保护的 POST /cad-current-states，每次1–50个唯一读取编号；验证所有记录归属与完整性后，核对当前文件哈希、读取时绑定和解析器版本。只返回状态及来源标识，不返回几何、不改历史。同批同原件只检查一次，解析器版本每批检查一次。

页面每页20条，每5秒核验可见记录，4秒超时撤下数量。首次、失效恢复或记录变化必须重新获取详情；同哈希正常轮询不重画明细，不重置构件选择。网络失败、解析器不可用、原件变化均不能显示旧数量。迟到状态和详情响应不能覆盖较新的失效结果。隐藏页面清空数量并暂停 CAD/并集轮询，返回重新核验。并集来源选择在核验完成前禁用计算。
