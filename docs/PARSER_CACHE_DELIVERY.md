# 解析运行库核验性能增量

本批处理 PARSER-05 的 Windows 首次缓存复用延迟。源码基线为 PR #24 合并提交 `45786999939a1159c2b1822a193717abeac277e6`。实现提交 `947ad6ca19077dc9ac4c67c9b021732cc0df2400`；证据索引见 PARSER_CACHE_EVIDENCE.json。评分保持70，不把局部提速换算成专业能力或生产稳定性得分。

## 改动及完整性约束

`parser_runtime_cache.get` 仍先检查原安装文件的大小/mtime和缓存的完整目录清单，随后读取每个缓存文件的全部字节并比较 SHA256。Windows且至少128文件时，用至多8线程、8个分批任务并行读取；小缓存和Linux继续串行。线程池退出前等待所有任务结束，读取或校验异常不能漏过。现有全局缓存锁保持，单进程不会因两次并发解析叠加成16个核验线程。源文件stat从两次合为一次，没有移除任何字段检查。

资源回执新增 `runtime_verification`：文件数、耗时和配置的线程上限。`workers` 是线程池配置上限，不承诺每次实际调度了相同数量的线程。首次复制仍在有界复制过程中逐文件哈希。原文件、公式、模型、输入副本、LPAC/Landlock/seccomp、工具授权和失败拒绝均未改变。

解析器版本包含该代码身份，因此旧解析记录仍按现有契约失效，不修改旧manifest。物理核心哈希保持 `24980c3a62cfba035267af7df98b7775fec71a9958c9049eec31218179f32199`。本批没有新跑年度EnergyPlus，不沿用上一批数量冒称本批模拟通过。

## 实际对照

同一Windows主机、固定DXF的3000×4000 mm线段，独立答案5 m。六个全新Python进程按基线/候选/候选/基线/基线/候选顺序运行，每个进程连续解析三次。基线从上述Git提交读出原缓存模块，在验收脚本内显式替换；只补空的计时兼容字段，不替换结果、不伪装成候选产品验收。候选使用实际产品代码。每次都启动真正的LPAC解析进程，验证5 m、隔离回执、原件哈希和任务清理，18次全部通过。

|调用阶段|基线中位数（范围），秒|候选中位数（范围），秒|
|---|---|---|
|新进程首次解析|22.06（21.26–42.95）|20.84（20.80–23.57）|
|第一次缓存复用|26.85（25.00–27.69）|7.79（7.60–8.36）|

第一次复用端到端中位耗时减少70.97%，准备阶段中位数22.125→2.828秒。每组仅3个进程；首个基线冷调用与短暂完整性专项测试重叠，故不据冷调用差异作因果结论。对照没有清空操作系统文件缓存、控制系统安全扫描或测试生产多用户吞吐；后续热调用存在12秒左右长尾，不能宣称每次低于8秒或建立硬延迟SLA。

之前单次预试与本轮全部分次日志均保留在 `validation/parser-performance-20261105/`。`comparison-summary.json`保存全部值、中位数和范围，`compare_cache.py`保存基线加载与实际调用步骤。

## 正反测试与运行结果

新增7项完整性测试：真实读取所有256个合成文件；通过同步屏障检验并发上限；首部、中间及末尾文件被同大小替换并恢复原mtime时仍拒绝；末批读取失败等待线程退出，恢复后再次核验成功。没有用大小/mtime代替字节哈希。

Windows和Linux各 **84 passed / 2 skipped** 的解析专项通过，分别381.04/144.49秒，覆盖CAD、PDF、OCR、缓存、隔离、缺依赖、资源失败及恢复。Linux来自非root WSL独立源码副本；Linux两项跳过是Windows专属，Windows两项跳过是Linux专属，不计通过。首次工具沙箱不能建立pytest临时目录，7项均未执行；原错误日志保留，随后在既有本机隔离验收环境运行。

Windows公开Duplex IFC再次核对295产品/空间关系、108矩形拉伸体和21声明量；公开旧图仍为预选12处中10处正确、43候选。七张退化/空白合成图的原缺口保留。没有把性能优化当识别率提升，也没有把网格量当净工程量。

本轮前端源码未改。新浏览器复验因本地会话过期，恢复历史测试凭据并暂存的操作被自动审批拒绝，已请求明确补充授权；尚未执行新登录，因此本轮界面验收记为待验证。上一批浏览器通过不能替代本批状态。服务正常退出码0后启动候选版本，未强杀，也未因此声称主API强杀恢复完成。

PR #25 首轮精确提交 `2134aee64fca702ac121180e89016f52e06f0a5e` 的六项push/PR检查全部成功。两份远程全量后端日志均531 passed / 18 skipped / 6 subtests，193.66/156.76秒；前端和契约检查通过。远程没有安装EnergyPlus，跳过项不计引擎验收。补入本段与证据索引后的最终文档提交仍需六项成功；最终身份另存本地release-receipt.json。
