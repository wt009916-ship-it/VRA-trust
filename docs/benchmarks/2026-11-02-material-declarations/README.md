# 官方材料碳声明接入与实测

本轮使材料资料从论文检索进入“检索官方声明→声明量换算→按工程量核算→带入改造包→保留适用性复核”的实际功能链。不是整产品企业级签发验收。

## 真实来源

[ÖKOBAUDAT官方导出](https://www.oekobaudat.de/en/service/downloads.html)实际下载51,516,005字节，SHA256 `b501bf3c9a27b9a33ce613fd2945fd36ea9a788786292ac7f77c3a4484a488ab`。原CSV为cp1252、分号分隔、点号小数，完整保留本机，不改写或上传大文件。4,308个UUID/版本数据集、44,973条模块行；其中具体产品1,565，平均2,096，通用572，模板52，代表23。不是4,308个合格稀土产品。使用条件见[官方数据用户说明](https://oekobaudat.de/en/guidance/data-users.html)。地区、背景数据库、标准、声明单位/量、年份、情景与原始行号均保留。

## 已实现

独立SQL分页检索、来源性质/单位筛选、原件版本归档；A1–A3及完整A1–A5计算；按原声明量而非默认1单位换算。聚合制造模块与A1/A2/A3不重复求和；模块D不进入材料GWP，更不兑换信用。允许来源明确的负值，保留生物碳及生命周期边界限制。

缺原件或哈希改变、未知单位/声明量、缺GWP、旧A1口径、缺模块或多情景均不输出金额/碳量0。仅有到期年份且本年到期时，要求核实确切有效日，未猜测年底。工程量单位不一致时不猜密度/厚度。改造包重新使用当前实际部位工程量核算；手填因子与绑定原件不同则409；本工程适用性依据未确认时不产生确定项目材料碳。原有费用/生命周期/信用限制保留。

入口：项目→材料与决策→整包投资比选→官方材料碳资料库。声明可带入已有部位，仍须提供工程适用性来源和真实报价。保存的来源版本及原始行随报告保留。API受账号、项目归属与CSRF保护。

## 实测

20个不同具体产品声明，覆盖20个分类；先冻结名单，再独立使用原CSV与Decimal核对。13.75声明单位是明确的测试工程量，不是原工程BoQ。20/20、200/200来源与算术检查通过。另1,000次隔离TestClient顺序读取全部200，41.33秒；不是生产并发SLA或1,000次真实按钮点击。逐例见[结果](results.json)。

DeepSeek官方两轮任务均实际调用epd_search与epd_calculate：一轮正确单位得出GWP，一轮质量/件数错配返回null并拒绝换算；共6次模型请求、29,688已报告token。解释明确未审核工程适用性和未签发信用，第二轮将因子称为“单价”措辞不精确，保留原答复；未训练权重。见[真实调用](agent-results.json)。

后端458项、6子测试通过；先行EPD/改造包/来源39项专项通过；前端61项通过，Ruff、公开边界、契约及公开/本地构建通过。浏览器实际登录隔离账号、检索LinCrete、1000kg声明量换算到13.75kg=11.65kgCO2e、带入已有kg部位并提示补工程适用性依据通过。完整保存重开与跨浏览器、本轮独立工程师复核未新验收。
