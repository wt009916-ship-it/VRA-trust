# 共同工程量与整包投资比选验收

2026-11-01。本轮是确定性采购计算、来源门禁及实际浏览器流程验收，新增真实工程验证0。没有商业竞品同题实跑、稀土材料实测、正式工程签章或训练权重。

## 本轮实现

共同工程量/单位/性能范围 → 每包每部位的具体产品版本 → 五类含税初始费用 → 工程适用性与来源 → 预算、材料阶段碳和维护/更换费用账本。支持UTF-8 CSV工程量、JSON工作文件、先检查再保存、历史重开与副本修订、带输入来源快照的HTML复核报告。

费用缺项、缺工程量来源、漏部位、错误单位、失效报价与未满足工程条件分别处理；0元须有依据。没有完整数据时不发布整包金额或生命周期费用；未将独立仿真节能相加。范围及公式见[使用说明](../../RETROFIT_PACKAGE_COMPARISON.md)。

## 数值验算

采用明确标注的合成外墙/屋面两个部位，非真实工程：

- 初始五类费用分别合计130与260元，整包390元。
- 年维护费合计9元，20年维护180元；10年寿命，期间仅第10年完整更换150元，期末20年不再次更换。
- 零折现率的已声明支出390+180+150=720元；5%时与独立年金公式及第10年折现相符。
- 共同工程量100与10m²，同阶段因子2和3 kgCO₂e/m²，初次材料碳230 kgCO₂e。
- 预算390元时预算内，改成380元后浏览器显示超预算。不能据合成小金额推断商业价格。

专项覆盖五种费用各自遗漏、工程量缺证、未知维护/寿命/GWP、遗漏部位、防火不满足、更换时点、过期报价、证据撤回、错误单位、重复替代、无依据0元、非有限数、CSV引号/BOM/错误行、跨账号与CSRF。
