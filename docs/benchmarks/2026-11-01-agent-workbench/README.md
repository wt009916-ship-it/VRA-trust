## 独立核验与已知错误

- 两轮各直接用IfcOpenShell读取两份IFC，全部工具计数与源文件一致，共4次比较；共用底层解析库，不能证明解析库本身、几何拓扑或现场一致性。实际计数、文件哈希见[audit.json](audit.json)。
- 9份已保存材料提议的条目全部来自本任务成功检索，工程量/价格/节能/签发量字段全null。只核验ID来源约束，不证明模型所有文字解释。
- 两轮天气结果均8760条及9.761°C；未授权控制不创建分析；全部模型任务没有创建EnergyPlus作业。
- 第二轮窗任务与接续说明把0份登记证据说成0份原件，实际当时有3份上传、1份天气分析。保留错误历史；给诊断及Gate工具增加明确分阶段计数并修订策略，没有重写旧回答。最新真实复验受402阻断。
- “全部条目已读取”仍不等于读过全部论文全文；实际只发送当前索引的有范围摘要/测量记录。材料条目仍49，全文归档仍36，本轮没有新增论文采集或训练数据批准。

## 产品和回归

前端显示AI说明、计划、提议和问题，支持历史重开及关联接续；历史下拉只取30条摘要，按需读取完整轨迹。提议进入已打开材料页时只更新提议区、保留原表单，并自动展开定位。安全转义文字/表格，不执行模型HTML。

最终完整后端首次424通过、2失败、2跳过、6子测试通过；两失败是启动验收时漏设ENERGYPLUS_EXE，指定实际9.0.1引擎后原生专项31通过/6子测试通过。另最终专项45通过，前端60通过；Ruff、语法、公开边界、契约导出与公开/本地构建通过。两个跳过是该进程缺引擎路径导致；设置实际引擎后图纸热模型专项10项全部通过，包含原先跳过的两项。没有把补跑拼成一次全绿完整运行。

隔离浏览器实际登录、任务历史重开、关联提议、带入材料工作区、390/1440宽无横溢出、console error 0。旧任务的错误说明仍保留，页面不把它改写成新验收。用户补证提交的前端成功路径仍依赖服务商恢复，受控测试已验证关联ID和权限重置。
