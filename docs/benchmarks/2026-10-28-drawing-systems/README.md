## 图纸控制与真实老图

固定旧版`floorplan.py`，同一两房间的12组倾斜/褪色/短断线扰动，按原始像素坐标的IoU≥0.9匹配。旧版4/24，新版24/24；同一闭合预算，控制对照两边均关闭OCR，避免把文字耗时混入几何对照。最终脚本观察的几何均值约13.38ms/58.34ms，增强初次处理更慢。这不是12栋独立建筑、留出集、真实老图准确率或竞品对比。

公开施工预览图保留6候选。三次观察的冷/热识别分别约5.21/0.022、7.17/0.028、7.76/0.038秒。热调用是同源/同规则/OCR模型匹配的进程缓存，没有“首次识别快几百倍”的结论。[逐项控制、哈希与耗时](drawing-benchmark.json)。

真实输入为麻省大学Fiske Center报告中再版的1936年HABS马车房平面，第24个PDF页（印刷页12）。不是原始HABS母图，比例尺为人工近似读取15ft/117px。实际API得到5候选、154补接提议，**主要大空间尚未恢复，整张平面未通过**；两条人工门槛分区假设也没有解决完整性。浏览器另完成一条原始像素补接→新任务201→补接依据持久化，证明操作链，不计作整平面成功。首轮小退化轮廓异常保留，修正后仍保留排除原因。[候选/补接与限制](historic-drawing.json)。
