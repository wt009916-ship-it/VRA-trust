## 20个实际气候格点

[NASA POWER官方Daily API](https://power.larc.nasa.gov/docs/services/api/temporal/daily/)提供日尺度格点气象/太阳数据。本轮一格点一次远程请求，保存原始响应；20地点为南昌、哈尔滨、北京、上海、广州、昆明、拉萨、乌鲁木齐、兰州、重庆、三亚、福州、伦敦、迪拜、新加坡、奥斯陆、凤凰城、悉尼、开普敦、圣保罗。固定2024全年、LST日尺度、366天/地点，共7320条日记录。格点/再分析不是建筑现场测量；不能转算20栋建筑或直接代替逐时EPW。

每地点10项检查，共200项通过：366行、源值独立算术年均温、HDD18、CDD26、全年辐射和、保存重开与SHA、CSV366行、重复请求复用原件、HDD20及CDD24本地替代分析口径。年度算术直接由源值计算，不调用产品aggregate函数作为oracle。只是天气路径，不是所有变量/所有功能的准确率；NASA本身的气候科学准确性也不由此验证。全部地点/哈希/结果见[逐例结果](climate-results.json)。

80条标签来自20原件×4年度指标，source_nature=reference，training_permission=unknown，reserved_benchmark=true，独立复核0、训练导出0、训练0。跨时期/问题变体不能重复当作独立建筑。

## 数据库和后台

为records增加kind/project/id/revision索引；后台列表改服务端SQL分页及状态/功能/来源、问题、项目组检索，概览只读取必要字段。按规范化项目组去重；人工纠正来源性质后统计采用有效复核值。增加16功能维度，将标签、来源组、已复核出处、已登记运行及不同原件分开。0份登记不代表历史从未测过。

5000行独立合成负载库，5轮交替比较：旧方法完整反序列化再取20条，中位144.81ms；SQL分页同20条，中位9.49ms，ID/顺序一致。负载库不进入正式库、不计真实案例；测试期间同机还有其他测试运行。这是局部查询计时，不是生产容量或SLA。[全部计时](database-benchmark.json)。

后台代码、专用管理接口和原件仍仅本地。安全检查覆盖匿名/非管理员拒绝、CSRF、原件哈希不一致拒绝、重复导入、组别/原件防泄漏及禁止自动授予独立批准。浏览器实际登录、Nanchang+weather_analysis筛出4标签、归档接口200；下载事件等待工具超时，未将客户端保存文件内容当作已核验，服务端文件哈希/响应字节及20归档源另外核验。390/1440页面无横溢出，console error 0。

## 失败与修复

首轮20地点在CSV检查处报“initial_value must be str or None, not bytes”，属于验收脚本未解码字节，并非20个NASA输入无效；原始记录与失败保存。修复后使用同一缓存重新执行后续检查，无重复下载、无填补源值。材料采集首轮因EuropePMC许可字符串被当列表对象而中断；改为保留许可文本、仅从字典列表读取URL后缓存复跑。最终缓存对URL和原始内容SHA做归属核对，错误查询/污染缓存拒绝复用，不能把旧响应标成新检索。
