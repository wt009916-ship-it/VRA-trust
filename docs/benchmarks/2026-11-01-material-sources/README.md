## 实际采集方式与失败

- Crossref九个主题首批每题12条，共108条DOI元数据，其中44条有API摘要；按题名初筛41条，仍含跨域结果，不自动进入材料推荐。
- Europe PMC五个查询均返回503，各按策略短暂等待重试一次后记录失败；没有伪报零命中或全文成功。
- 改用NCBI官方PMC检索，四个有界查询合并35个ID；逐篇检查34篇有正文，1篇只有元数据。另三篇指定全文中两篇不在上述集合，合并共36篇正文。
- 对13个明确DOI另行核验，13个元数据成功、7个API含摘要。合并所有来源，按DOI形成154条检索池，保留151个题名组及未复核记录。
- 多文章XML批次成功不能代表每篇都有正文，故另按文章拆分、正文检查并使用论文检索技能的JATS解析器逐篇验证。成功HTTP但缺body的记录不计全文。

公开采集器可复跑有界查询：

```powershell
.venv/Scripts/python.exe scripts/collect_material_sources.py --output ../material-source-intake-new --until 2026-11-01 --with-pmc
```

查询结果会随数据库变化，上述指纹记录的是本轮固定下载，不承诺将来检索结果字节相同。采集器不自动批准材料卡、写产品因子或训练模型；输出位置须与公开发布包分开。
