## 已保留的失败

初次后端测试因沙箱临时目录初始化失败（13通过、8初始化错误），正常隔离测试环境复测通过。首次构建的Windows npm参数转发错误，改用已安装Vite直接构建后通过。UI启动脚本错误地要求注册201，实际接口200；修正测试脚本并改用新隔离库，未修改正式接口掩盖失败。浏览器发现玻璃方向不应转为不透明墙体材料，已限制转换。两条DOE旧链接读取404，常规对照改用可读取的DOE教学资料和NFRC原文。

初次失败日志、隔离测试记录、原始模型回答与完整恢复包留在本机，不把运行库、会话、API配置或受限全文推到GitHub。
