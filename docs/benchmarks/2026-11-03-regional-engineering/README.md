## 气候：从资料目录到原件核验

[Climate.OneBuilding 中国目录](https://climate.onebuilding.org/WMO_Region_2_Asia/CHN_China/index.html)及其[香港目录](https://climate.onebuilding.org/WMO_Region_2_Asia/HKG_Hong_Kong/index.html)、[台湾目录](https://climate.onebuilding.org/WMO_Region_2_Asia/TWN_Taiwan/index.html)实际解析2,777个档案版本、879个地区/站号组合；不是2,777个独立站点。分层选取33个地区各2站，再补江西赣州和南昌，下载68份原始压缩包和EPW，逐文件保存SHA256，合计595,680条小时记录。

最初66份全部阻断，多数新版源文件每小时采用固定分钟30。按[EPW字段说明](https://energyplus.readthedocs.io/en/stable/auxiliary-programs/auxiliary-programs.html)与实际原生运行，兼容逐时SRC-TMYx和ERA5-TMYx的固定分钟30；保留原值，仍拒绝混用分钟、缺小时、重复和子小时记录。第一轮兼容后64份通过；复验基隆ERA5-TMYx后65份通过，再补两份江西文件，最终**67/68通过**。北京密云544160有29条DNI异常保留阻断，未补零或手改原件。所有原始小时序列独立核对，67份通过原件下载字节核对，阻断文件下载接口404，匿名401。[逐文件检查](weather-api-results.json)

6份未改写EPW与同一参考五区模型运行原生EnergyPlus 9.0.1成功，0 Severe，保留每个运行4–5项Warning（具体见原ERR摘要）；不代表6栋实际建筑能耗。澳门源EPW子页404；另用[NASA POWER日尺度](https://power.larc.nasa.gov/docs/services/api/temporal/daily/)取得2024年366日、无缺测。澳门仅日尺度参考，不能当EPW。33地区有已检EPW，加澳门日值，34地区可检索；不称每个地块有实测或极端设计天气。[原件来源与失败](sources.json) · [原生验证](native-weather-results.json)

## 中央冷站：定位单位链，不伪造现场校准
