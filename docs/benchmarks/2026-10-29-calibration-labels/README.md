## 一栋实际冷站、两台冷机

原件来自Vanderbilt Engineering Science Building作者公开历史提交 `0ffc3c8234ecca50606cfd9ed1e1d464f998b832`。文件为现场记录经作者处理，包含删除停机/异常状态、天气推导等加工，并非未经处理的全年原始计量。两个文件分别4,094与7,754行，时间仅覆盖2018年5月至6月的一部分。

采用作者声明的W/K/m³/s，`Tons`列按W读取；五月时间以作者代码CDT(-05:00)处理。水密度997kg/m³、比热4180J/(kg·K)和10%平衡预算是明确的诊断假设，不是现场标定结论。留出期统一从 `2018-05-28T00:00:00-05:00` 开始，不用留出误差选系数。
