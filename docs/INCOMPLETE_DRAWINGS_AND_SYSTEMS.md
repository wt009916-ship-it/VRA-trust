# 老旧图纸、室内构件与中央系统

2026-10-28 工程预览。最初主线仍是既有公共建筑资料不完整时的改造决策：图纸分析必须帮助恢复可检查的候选、定位不能恢复的部分，并允许工程师回源接管。本轮的图纸增强、构件与系统都有实际代码和验收；完整破损建筑自动恢复与完整高楼热模型仍未完成。

## 从老图开始

在「建模工作区 → 导入资料」选择 **老旧图纸增强**，打开图页后框选平面、标定尺寸并记录比例来源。当前处理PDF/PNG/JPEG的2400像素以内预览，原件保持不变。

增强流程复用OpenCV：局部背景归一、可见长线方向估计与有界倾斜校正、多方向线提取，再生成闭合区域。坐标通过逆变换回到原图，比例不变；OCR读取房名和图注面积，可关闭，面积文字不用于强行缩放轮廓。

门窗闭合与断线补接默认0。自动补接会保留逐处原图坐标、增加的线墨及距离上限，用红色虚线叠加；它可能是门洞或标注，不能据此认定存在一堵墙。增强模式也不能恢复完全不可见的房间、缺页或楼层，候选多不等于完整。

当自动识别失败，可在原图上选择「人工补接」，点击已核对的缺口两端并填写至少10字符的依据。每次最多100条，每条2–400像素且不超过5米。紫线表示人工分区假设，既不证明是实墙，也不自动得到门窗面积和热工性能。识别记录的「在此原图上继续修订补接」复用同一项目原件并创建新识别任务，旧任务和模型版本继续保存。

接受候选后，比例、补接和增强依据随模型来源保存，自动进入「工程复核」。空间用途、层高、围护结构和设备仍须补齐。没有闭合空间时，任务失败并保留图像分析与补接诊断，不能改成示例成功。

同一原件/参数/规则/OCR模型的重复识别采用进程内8项有界缓存；每次核对原件哈希，返回副本。修改文件、参数或模型后重新识别；不是跨项目共享权限，也不替代来源校验。

## 工程构件与室内

项目顶部新增独立 **工程构件与室内** 视图。选择已上传IFC或上传原件，读取源楼层后提取实际网格。支持墙板柱梁屋面、门窗洞口、楼梯坡道栏杆、机电分配构件，以及源文件已有家具。按楼层、类别与源名称/GlobalId筛选；点击实体可回看IFC类型、楼层和原件属性。

采用IfcOpenShell/OpenCASCADE实际三角面及原生洞口扣减，不用包围盒代替构件。缺几何表示和提取失败项继续计入清单；不存在的家具、空调或管线不会自动生成。坐标平移应与建模工作区原点一致。预算为15000构件、200万三角面与解析检查点120秒；超预算拒绝并要求选楼层，这些是保护上限，非容量或耗时承诺。

源属性名称/数值保留，不推定其单位或厂商性能已经核实。构件视图与热模型分开：有一台空调的几何，不表示已知COP、连接回路、控制或安装性能。源家具显示已实现；缺失家具的图纸识别、照片还原和自动布置仍未实现。

## 中央冷热源与水系统

在「建模工作区 → 热工」展开 **中央冷热源、水泵与风机盘管**。当前支持四管制风机盘管、风冷/水冷冷水机组、燃气/电锅炉、冷热水泵，水冷另含冷却水泵与冷却塔。使用EnergyPlus9.0.1原生HVACTemplate与ExpandObjects展开真实回路、节点、设备和控制，保存输入及展开文件，再执行原生全年计算。

参数须有依据：冷机COP与可选绝对容量、锅炉效率/能源与容量、供回水设计温差、各泵压头、风机效率/压升，以及完整冬夏设计日。冷热源容量留空明确表示设计日自动选型；末端盘管与水流量按设计日选型，不代表已安装铭牌。新风使用逐时运行档案；当前不包含新风热回收器，非零回收效率会拒绝，不静默忽略。

可上传项目中央设计JSON，一次读取参数并绑定文件ID/哈希；也可直接填写明确情景。JSON字段与示例见[中央系统输入契约](../examples/central-system/README.md)。来源文件损坏、跨项目引用或哈希变化拒绝保存。系统不能与独立PTHP或逐空间PTHP清单混用。

当前只支持原生通用参考性能曲线，因此即使设计文件有依据，生成IDF仍为ASSUMED并产生专门复核项。不是厂家变工况曲线或现场校准。结果按电、燃气及水泵/风机/排热等原生SQL分项显示，与理想冷热需求分开；成功运行和低能耗也不表示容量、舒适性或工程适用性合格。

尚未自动翻译源MEP连接图，未实现管长热损、详细水力平衡、分区供压、立管高度与水泵扬程自动计算、复杂群控、VRF或任意中央系统。高楼静水压力、供压分区及设备选型尤其需要专项设计，不能由可运行的回路模板推导已完成。

## 复杂高楼修模

几何归并可选「在上限内逐步收紧」。候选破坏局部拓扑时保留该原空间；分段归并后同步底面，并检查单空间面积/体积预算（0.5%与0.01绝对量取较大者）及整版模型。数值焊接可在原10微米限额内拒绝超限传递链；极小成对面须同步处理，原累计面积/体积保护仍执行。

窗墙比还可选择同空间、同平面外墙的面积预算：不在不可表达的细碎热面强行造窗，而在可表达面分配并核对该立面总面积。此操作仅限明确假设情景，记录排除/重分配，不作用于源窗。可表达外墙不足时继续阻断。没有通过删除空间、改写边界或降低实际窗面积来凑通过。

真实De Zalmhaven299候选仍在测试中暴露细碎边界和开窗覆盖阻断；原结构文件也没有源立面、用途与机电。该项目仍未完成完整热模型。详见[本轮数据与失败](benchmarks/2026-10-28-drawing-systems/README.md)，不能沿用其他建筑的成功冒充高楼成功。

## 怎样理解本轮实测

- 固定旧版识别器，同一两房间几何的12组褪色/倾斜/断线控制，按IoU≥0.9，旧版匹配4/24房间，新版24/24。它们是作者控制扰动，不是12栋真实建筑、留出集或商业软件对比。三次观察中增强的纯几何均值约54–58ms，旧版约13–15ms；当前精度改善有计算代价。
- 公开施工图6候选，首次增强识别多次观察约5.21–7.76秒，相同资料重复约0.022–0.038秒；后者来自缓存，不代表首次识别或对竞品的加速。这轮没有“整体更快更准”的市场结论。
- 1936年HABS马车房平面图的大学报告再版，实际上传/识别得到5候选及154补接提议。主要大空间未恢复、若干区域被排除或阻断。尝试两条人工门槛分区线后仍未完成整平面，不能当成功案例。比例尺为人工近似读数，没有独立工程真值。
- 实际FZK提取57构件；KIT提取988构件，其中253源家具。独立社区Duplex MEP原件提取926源构件，包括427管段、358管件、105末端及其他控制/设备；只是原件分类，不代表现场或热模型连接验证。
- 公开FZK7空间、KIT82空间的中央系统均完成365天原生计算，分别0/1警告。KIT警告为393个低于0标高表面；设计盘管还存在需复核的尺寸提示。水冷控制有参考曲线IPLV工况警告。全部保留，不能称零诊断或现场设计已合格。

当前成果是可用链路和已复现问题的工程预览，不是任意破损图纸、高楼或设备系统自动完整恢复。完整测试、源码/原件哈希、实际性能与失败见[脱敏验收记录](benchmarks/2026-10-28-drawing-systems/README.md)。
