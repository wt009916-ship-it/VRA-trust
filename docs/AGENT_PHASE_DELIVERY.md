## 能力、对照及独立答案

当前应用的长系统指令同时要求“来源、缺口、准入必须回答”和“只回答本次任务所需内容”。计划阶段只允许一个输出计划工具，却还承担计算、能力查询、读取及完成报告的指令。本批为该阶段单独提供当前问题、合法字段/主题、来源与授权边界；源状态和必要范围提示仍由应用核验。未按关键词删除模型输出，未将意图标成已认证，未放宽工具授权、5轮/15事件或数值校验。

运维 CSV 缺失/缺口影响整体核验，但样本数、缺失单元数、缺口数、规则事件数之和及未知样本数之和仍是可核验的观测事实。候选仅对这些字段复用原来源读取、数值/单位/期间核验及最终重读；stale、未知字段和其他专业不适用结果仍拒绝。原记录状态与artifact.verified不变，不能诊断故障或推荐控制。进度界面对部分结果显示“所列字段已核对 · 整体记录仍受限”。

两批均为开发者设计的固定输入，每题每模型一次应用调用；应用原有有限重试保留，没有训练或改金标准。第一批24题是在旧应用上比较模型：4B严格0/24，9B严格8/24；包括两个应用无法表达的要求I07/I08，不剔除失败分母。不能把9B参数规模或公开榜单当能力证明，未切换正式模型。第二批8题在实现前冻结题目、参考值、修复方案及采用门槛，同一4B/8192上下文/1400输出预算/温度0/关闭思考：基线1/8，候选5/8；修复P02/P06/P07/P08，无已通过项回退；P03/P04/P05仍失败，停止本题调优。共64次真实推理，原始消息、响应与应用任务保留。首题I01因测试器异常从隔离数据库只读恢复，没有重新请求；该题端到端耗时未知标null。
