# 二维稳态导热：候选实现与验收

2026-11-14。本批在 PR77 的 `fbcbaf1472342e7948e60643344dd831e381fcc1` 上开发。尚未合并 main、尚未更新正式原型。正式版本 76 分，已复评候选 78.5 分不变；本批不凭新增入口或稀疏参考点通过而加分。

## 实际能力

新增 `thermal_bridge.py`、`thermal_bridge_solver.py` 与项目作用域 API：明确矩形外边界、最多 32 个矩形材料区、导热系数和单位、四边表面温度／空气温度及表面热阻／绝热条件。按界面分网格，以半单元串联热阻构造保守有限体积通量，求二维稳态温度场、表面热流与每米延伸长度热流。所有材料和工况由用户声明，缺失值不补默认计算。

计算同时运行初始和半边长网格，分别报告真实线性残差、热平衡和两网格差异。网格最多 160000 单元，求解预算 25 秒、6000 次迭代，实例单任务容量。超限不保存成功结果；并发忙返回 429。坐标支持 m/cm/mm，导热系数支持 W/(m K) 与 mW/(m K)。表面热阻单位固定为 m²K/W。

应用入口在原热工页的“二维材料截面”折叠区域，具备分区草图、四边输入、取温点、证据关联、温度场、当前历史、CSV／JSON／HTML 报告。计算服务接入原项目归属、登录、CSRF、证据版本与原文件复核。来源、项目或计算器变化后隐藏旧数值；历史原始记录保留。没有改动旧一维热阻计算或自动修改 IDF。

明确未做：非矩形外形、各向异性、接触热阻、热源、辐射空腔、ψ 自动提取、结露、全楼能耗、标准认证、实楼验证及 Agent 自主二维建模。用户暂缓的浏览器验收仍未执行；单元测试与构建不代替界面验收。

## 独立交叉验证

实现前冻结 `analytical-reference-frozen.json`：独立分离变量级数的 28 个温度点，Decimal 平板／串联／并联热流。公开复合截面的坐标、9 个温度点、9.5±0.1 W/m 热流在第一次复合求解之前另行冻结。没有根据产品输出修改预期答案。

依据：[ISO 10211 官方范围](https://www.iso.org/standard/65710.html)、[Fraunhofer WUFI 公开二维基准](https://wufi.de/en/two-dimensional-test-cases-of-iso-10211/)、[LBL 对误差指标的说明](https://windows.lbl.gov/error-energy-norm-and-isoen-standards)。仅取公开物理设置、数值与方法说明，没有复制完整标准，也不声称标准全部验证。

实际 HTTP 结果：

|案例|独立参照／验收界限|实际结果|判定|
|---|---|---|---|
|均质四边换热二维场|对称中心 10°C；两网格温差≤0.1 K、边界热流相对差≤1%|中心满足 1e-8 K；温差 0.00745327 K，热流差 0.135625%|数值检查通过，非合规结论|
|公开复合截面 9 点|每点误差≤0.1 K|最大误差 0.04089534 K|这些取温点通过|
|公开复合截面热流|9.5±0.1 W/m|9.48611485 W/m|热流参考通过|
|同一复合截面全场网格检查|最大两网格温差≤0.1 K|约 0.278097 K，未达标|`needs_refinement`，仅供诊断|
|复合截面更细网格诊断|不降低原门槛|25050→96000 单元，温差 0.133544 K；热流 9.489322 W/m|仍未达全场门槛|
|继续细化到 0.8 mm 初始边长|保持容量与时间预算|求解预算耗尽，拒绝结果|不能包装成通过|

均质角点温度不连续的公开案例，其 28 个远离角点温度通过独立级数对照，但角点总热流可能奇异，保持未通过网格状态。线性方程残差小不证明工程离散误差小。公开复合截面温度／热流参考通过也不覆盖未通过的全场检查。

## 缺陷与限制

### TB-01 · 多材料界面取温错误（高，已修复）

- 功能：指定位置温度。复现：厚 0.16 m、λ=0.8 与厚 0.06 m、λ=0.04 串联；空气 21/-4°C、表面热阻 0.12/0.05；取 x=0.16 m 界面。
- 预期：独立串联热阻得到 16.721925°C。实际初次：普通线性插值得 14.480654°C，相差约 2.24 K。
- 证据：`interface-first.log`；修复后 `solver-interface-repair.log` 和最终后端日志。
- 修复：按两侧半单元导热热阻重构界面温度；另验轴交换后温度场、热流及取温不变。多材交点仍标记为网格近似。

### TB-02 · 高导热细网格的递推残差漂移（中，已修复并保留拒绝边界）

- 功能：高对比导热系数线性求解。复现：公开复合截面，初始边长 1 mm，细网格 96000 单元。
- 预期：重新计算的真实残差满足原数值容差，否则拒绝。实际初次：递推残差已小而真实残差超限，正确拒绝了输出。
- 证据：`composite-refinement-experiment.json`、`numerical-diagnostics.md`、`composite-residual-replacement.json`。
- 修复：通量差形式减少数值消减，真实残差不满足时重新启动 CG，最多 3 次；没有放宽容差。修复后真实残差约 1.78e-10 W/m。更细网格仍可能预算拒绝，未无限扩容。

### TB-03 · 公开复合截面全场网格误差尚未过关（高，未解决）

- 功能：复杂多材料截面可信度。复现：冻结复合输入，初始边长 2 mm 或 1 mm。
- 预期：全场两网格差≤0.1 K、热流相对差≤1%，且没有奇异角点。
- 实际：稀疏参考温度及总热流通过，但全场温差分别约 0.278 K 和 0.134 K；状态保留 `needs_refinement`。
- 证据：实际 HTTP 复合响应、细网格诊断响应。修复建议：后续研究局部网格加密及更有效的预条件，不放宽阈值，不将有限参考点当作全场证明。本批不继续无预算调网格。

### TB-04 · 验收脚本与测试的错误假设（低，已更正，历史不回填）

- 功能：测试工具。复现：首轮 HTTP 脚本错误要求注册返回 201；实际原接口为 200，尚未开展业务检查即停止。
- 预期：遵从原接口契约。实际：首次 0 项业务检查；更正后新隔离目录 19/19，通过记录不覆盖第一次。
- 另一次轴交换测试错误预设较粗的四材料场一定 `calculated`；实际场、热流、探针均轴交换一致，但网格差未达标。测试改为检查两方向状态与差值一致，新增平滑四边换热场单独验证真正的二维收敛；未改原阈值。
- 证据：`http-acceptance.log`、`actual-http/`、`api-first.log`、最终相关后端日志。建议：物理对照与收敛状态的预期分开冻结。

### TB-05 · 界面交互未做真实浏览器验收（待验证）

- 功能：新表单、材料草图、温度图、导入与历史。复现：需用户允许浏览器控制后实际操作。
- 预期：正常输入、错误提示、切换项目及导出流程均可用。实际：纯函数测试与构建通过，未做真实页面操作。
- 证据：前端日志及用户暂缓浏览器设置的指示。建议：保持待验证；不绕过设置，不因入口存在加体验分。

环境修复记录：隔离前端缺少 node_modules 链接导致第一次构建未启动。核验已存在依赖目录的 package-lock 哈希相同后恢复链接，构建成功。没有修改依赖锁文件掩盖失败；两份构建日志保留。
