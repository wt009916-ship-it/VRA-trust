# 项目中心、任务恢复与核对草稿 · 2026-10-25

本轮围绕用户管理多个项目、找到下一步操作、离开后继续工作，改进使用流程和视觉层级。它提升了可操作体验，不代表完整企业生产级交付或复杂建筑建模能力已经完成。

## 可直接使用的改动

- 项目中心来自新鉴权接口 `/api/workspace`，展示当前账号项目、待审资料、活动仿真、未归档批次和最近动态；跨账号及项目Token不能读取整个工作区。
- 搜索名称/地点/用途，筛选待办/计算中/已计算/参考，按更新/名称/面积排序，10条分页，列表或卡片；显示偏好可保留，搜索内容不持久化。空状态与连接异常有明确处理，失败同步保留上次状态并提示。
- 项目下一步根据实际资料/运行状态跳转到导入、复核、模型、天气或仿真；最近运行通过现有Domain.view检查当前有效性，不直接把数据库中的历史success当有效结果。
- 项目概览增加阶段入口和直接编辑建筑声明。哈希链接保存项目与专项页，支持刷新和浏览器前进/后退；不可访问项目回项目中心提示。
- 未归档批次可从工作区继续。新项目核对表在字段change时保存数据库草稿，返回和提交前等待保存；再次打开可恢复手工填写。草稿不是项目/证据确认，提交仍须显式复核；版本冲突409保留页面输入并要求重新核对。草稿不含“已复核”勾选值，不自动触发仿真。
- 统一工作区表格/卡片/状态、深绿侧栏和主次按钮；支持桌面、390px与深色主题。后台保留独立 `/admin`。
