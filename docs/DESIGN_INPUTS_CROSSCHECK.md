# 设计气象来源独立交叉验证

## 数据与方法

使用本机 EnergyPlus 9.0.1 WeatherData 中 San Francisco、Golden、Tampa、Chicago、Sterling 五份公开 DDY，每份 18 个设计日。原件版本与哈希见 [证据索引](DESIGN_INPUTS_EVIDENCE.json)及 public-input-catalog-v1.json。发行版本参考 [EnergyPlus v9.0.1 官方发布页](https://github.com/NatLabRockies/EnergyPlus/releases/tag/v9.0.1)；文件注释声明 ASHRAE 2009，不是对现行规范的认证。字段顺序与条件检查依据本机该版本 Energy+.idd。

独立答案通过逐行去除注释、字符分隔状态机产生，不调用产品 parse 来生成答案。核对 90 × 26 个设计日字段（含名称），以及 5 × 5 个站点字段，共 **2365 个原始字段**。产品解析与答案完全一致。另以独立读取字段构造显式改名模型，给出名称映射，五份均 matching_declared_fields；每份修改首日风速 +0.1 m/s，均只报告对应 wind_speed 差异。相同工作负载在 Windows 和非 root Linux 执行，案例回执完全一致，原件前后 SHA 不变。

这个验证证明有限公开样本的字段解析与映射，不能证明 90 次原生仿真或 90 个工程设计结果。没有重跑年度能耗，也没有把相等字段当作热工计算答案。物理核心哈希保持 465e405ca055907fe68396a5a19beff732d0ac58e7ac07cc820967f5713f8867。

## 反例与实际界面

独立合成测试覆盖同名异值（温度、压力、风速/风向、湿度类型、雨雪、夏令时、太阳模型、晴朗度、月份及温差）；负风速、非整数日期、NaN、超范围温度、湿球大于干球、错误枚举、零气压；错编码、截断、重复站点/设计日、引号字段和控制字符均拒绝。空白与默认值不合并；同名日程保持未验证；模型未覆盖设计日及其他定容工况均不包装成功。API 实测待复核拒绝、撤回失效、破损原件、跨项目/账号和比较期间模型变更。

Golden 浏览器模型两个设计日的 50 字段一致。冬季干球 -18.8°C、压力 81198 Pa、风速 3 m/s；夏季干球 33°C、日温差 15.2 K、湿球 15.7°C、风速 4.9 m/s。原件行号 26 / 202，模型行号 3900 / 3928，由结果报告保留以便复核。数据来源仍是公开参考输入。

双平台全量回归结果和跳过项见 [交付](DESIGN_INPUTS_DELIVERY.md)。可重放脚本为 validation/design-inputs-20261107/public_crosscheck_v1.py，参数依次为源码目录、全新输出 JSON 路径、包含上述 5 份 DDY 的天气目录。脚本不会下载资料或改写原件。

## 限制

原始字段数是解析覆盖数，不是独立物理模型数量。源文件日期/发布方为声明；日程内容、现行设计标准、气候适用性、太阳与湿热耦合、引擎实际采用工况仍需单独验证。单次本地解析耗时也不作为负载或长期稳定性结论。
