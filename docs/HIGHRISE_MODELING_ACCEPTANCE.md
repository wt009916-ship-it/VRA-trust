# 复杂建筑建模验收

日期：2026-10-27—28。状态：工程预览，覆盖扩展已实现；任意复杂高楼的完整自动热建模尚未完成。操作说明见[复杂建筑输入](COMPLEX_MODELING.md)。本页替代前一轮能力判断，[原失败记录](MULTI_PROJECT_ACCEPTANCE.md)保留。

后续增量见[老图、室内与中央系统](INCOMPLETE_DRAWINGS_AND_SYSTEMS.md)及[新实测](benchmarks/2026-10-28-drawing-systems/README.md)。FZK/KIT新增四管制中央系统全年情景；299候选高楼经多轮有界修模仍在同平面开窗面积预算处阻断，未执行高楼全年。下文为此前验收快照，不改写当时失败与manifest。

## 已改变的产品行为

- 无 IfcSpace 的 IFC 可从实际墙、板、柱截面生成待复核空间，保留逐层覆盖、原构件和未恢复区域。候选标为 INFERRED，用途与计面积默认留空。不同建筑、同名同标高楼层按实体归属处理。
- 闭合斜顶、倾斜及扭转的多面体保留实际壳面、体积和3D几何。曲面使用来源网格的折面，未实现精确曲面热面或任意破损实体修复。
- IFC和模型预算提高至2000空间；按建筑/楼层显示、搜索和批量用途确认不会隐式截断计算范围。DXF/PDF线环识别仍限100候选。输入预算不是生产容量承诺。
- 可采用源外窗/天窗的窗洞或组件投影，逐项保留面积、来源与调整；玻璃框、光学、遮阳及内窗传热未全面转译。逐空间PTHP可从绑定原件的CSV导入绝对铭牌及10项源性能曲线，未实现中央水系统或VRF自动编译。
- 修复源坐标过早舍入、近轴面UV翻转、接触面共线点被旧引擎删除，以及同平面反向小面被错误合并的问题。配对面两侧同步处理，累计面积/体积仍受严格预算约束。已知原生小面、三角短边和最大坐标投影面积规则提前阻断。
- 悬挑、错层等采用暴露楼面投影面积；复杂层高交给原生引擎推导，保留明确空气体积。可选柱体等效热容仅作用于来源确认的内部柱孔，保留竖井与原净空气体积，并声明近似。

## 实际执行与证据

使用当前编译器、IfcOpenShell和本机 EnergyPlus 9.0.1，保留原生SQL、ERR、输入快照及失败。脱敏结果见[本轮证据目录](benchmarks/2026-10-27-complex-modeling/README.md)。原件、数据库和大输出保留在Git之外。

### 16类控制几何

矩形、L形、U形、内院、多孔洞、退台、悬挑、裙房双塔、连廊、错层、单坡屋顶、四坡屋顶、倾斜实体、扭转折面实体、圆形32折面、椭圆32折面，共16组均完成：

1. 生成IFC并经实际IfcOpenShell重导，核对面积/体积；
2. 原始控制模型的独立Honeybee几何校验；
3. 实际EnergyPlus全年365天，**16/16成功、0Warning、0Severe**。

双塔和连廊各含3个空间，错层含2个空间；倾斜约18.4°、扭转15°。这些是作者构造的解析/回归样本，不是16栋真实建筑，也不证明任意曲率、角度、拓扑或网格密度都能通过。IFC往返证明空间几何守恒，不声称该测试导出了完整IfcRelSpaceBoundary热边界。

### 真实高楼：De Zalmhaven

使用[Esri/Royal BAM公开教程](https://learn.arcgis.com/en/projects/geolocate-a-3d-digital-building-model/)的原结构IFC，40,250,285字节，SHA256 `f32191d4330a610fc43924396e7321eab454ecbd68e3118d37d3dc579151b00b`。源含64个楼层对象、2,897墙、803板、1,039柱，0 IfcSpace、0源窗/门，缺少完整外立面和可用设备输入。

实际API上传201、读取64楼层、从实际构件恢复并保存**299个INFERRED空间候选**。6个源楼层仍有未恢复/小型区域，外边界缺证，默认发布409；本次没有产出可交付的高楼年度热模型。候选面积52,628.58m²是本次恢复口径，不能当作已核实建筑总面积。

另经真实HTTP上传并在独立浏览器打开整楼3D：全部299空间可见，64个楼层加全楼共65个显示选项；筛至第38层后全量房间选择器仍保留299空间，属性跟随当前楼层。299个用途均保持待复核，页面控制台0错误。三维预览成功不提高为热模型完成。

对299候选的探索曾暴露10万面预算、数值守恒和细碎外墙开窗问题；改进了全局网格处理并保留失败，但没有删除竖井、擅自改边界或伪造幕墙/设备来制造全楼成功。可选柱体近似也不能绕过这些要求。真实高楼的残缺立面、竖向分区和细碎边界仍是未完成项。

台北101的RWIND二进制风模型仍不支持；广州塔、央视总部未取得可核实完整工程原件，不能列为已测。公开教程可下载不自动代表有商用再分发许可，本仓库不分发上述原包。
