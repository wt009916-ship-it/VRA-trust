# IFC到梁分析交付：实施中，不计分

基于PR65/62047f9；实验图纸失败未混入产品。目标是IFC实际选定构件→截面几何和主轴惯性矩→人工明确力学假设→既有梁计算→同源报告及撤证失效，真实API和公开模型验收。整体G02不因局部核心过关而宣称完成。

1. 支持明确等截面参数轮廓：矩形、圆、锐角空心矩形、圆管及对称工字截面（包含根部圆角）。非零外缘圆角/翼缘斜率、非对称、变截面、曲梁、斜挤出、开洞等不得按外包矩形或锐角I梁冒算。
2. 原始轮廓坐标X/Y与明确选择的弯曲轴分开，禁止按世界包围盒猜截面方向。保留轮廓、实体、映射、单位来源；单位缺失/冲突拒绝。
3. 挤出长度仅是模型实体长度，不自动填跨度。支承、荷载、模量无明确证据保持缺失；人工确认不使数据变为实测，也不代表安全/规范通过。
4. 冻结独立IPE600圆角积分真值和正反例先于实现；真实公开直梁、曲梁、变截面、变挤出原件保留在C盘，按实际结构决定接纳/拒绝，不按文件名猜结果。
5. 后续必须接通隔离worker、来源记录、受审交付及表单/报告；不能只交付纯函数并宣称应用完成。测试包括失效撤下、写前变化和跨项目/CSRF边界。浏览器用户暂缓，仍待验收。
6. 新源码会使相关旧计算或CAD解析版本失效，保留历史，不重写hash恢复有效；正式原型当前不更新。
