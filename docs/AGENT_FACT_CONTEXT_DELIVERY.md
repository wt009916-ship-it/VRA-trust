## 实际改动

area_m2=null不再被工具schema解释为“总量而非单位面积量”。热工事实明确为固有面积归一化属性，阶段碳总量与使用声明面积的强度指标分开；评估期字段明确不是年量。R/U方法说明以及阶段排除信息传给真实模型。记录目录回执标注历史执行、数值有效性、功能支持和资料充分性均未评估，空目录不能据此推断。

原计算器、权限、模型预算和原型均未修改。新增5个用例，通过真实项目/热工/LCA接口验证面积变化不改变构造R/U、碳分母及期间一致、目录存在与历史/有效性判断分开。是契约与上下文修正，不是任意自由文字的语义验证器。
