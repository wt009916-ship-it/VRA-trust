# 建模覆盖、任务可靠性与运行恢复 · 2026-10-25

本轮补齐带孔空间、IFC 楼层/坐标范围、多项核查任务及完整运行备份。工程结果仍由工具和原生 SQL 给出，不能把解析成功、可读 AI 文字或恢复校验等同于企业级完整验收。

## 使用入口

- 建模工作区 → 导入 IFC → 展开「IFC 楼层范围」→「读取所选 IFC 楼层」。可明确选择楼层与按源站点原点平移。每次最多 100 空间，未选择的楼层、无归属空间均明确计数为未尝试；不会静默删除当前范围的失败空间。
- 孔洞作为外轮廓之外的显式内环保存，校验相交、位置和净面积，并确定性分解到热边界。二维图使用偶奇填充，三维与面积计算使用同一分段。IFC 导出使用带孔剖面，重新导入保持净面积和孔洞；不会把中庭填成空调区。
- 项目概览 → 项目操作，支持同一句天气/模型/仿真/材料/资料核查，逐项保留状态和工具依据。历史助手任务保存在数据库，刷新后可重新打开；轮询不重叠，切项目后停止更新旧输出。
- 独立 `/admin` → 数据库管理 →「完整运行备份与恢复演练」。数据库旧备份入口仍只备份数据库；新增完整备份同时包含原件、运行证据、工作流检查点及 private 配置。

## 智能体控制与真实调用

自动模式按所有匹配事项建立持久计划，公共工具只读一次，单项读取失败不抹掉其他已完成结果。计算授权、项目归属和用户提交的材料/反例/成本计划继续独立校验。模型缺少用户计划或替换计划时拒绝执行。

同一任务内相同的计算工具/规范化参数复用首次结果，记录原事件索引，防止重复排队；这不是跨任务的自动重试。工具参数JSON/类型/额外字段错误最多反馈修正2次；最多5轮、每轮4调用、事件上限36，轮间总时间预算180秒，单个Provider请求仍有60秒网络超时。无授权工具和计划越权不能通过参数修复绕过。

协议故障注入验证：无效JSON→修正→相同计算重复调用只发生一次实际工具调用（该用例为协议控制，未调用EnergyPlus）；无计算授权不提交；单项读取失败其他项继续；原有恶意计划替换用例保持拒绝。

真实本地Qwen3-0.6B-Q8_0连续两次对同一原始EPW项目核对天气/模型/仿真/资料：第一次Provider网络或响应错误，任务部分完成、工程工具保留；第二次返回可读文字。两次工具数值与原始天气来源保持一致，仿真任务均为0。可读文字尚未逐项评分，**不能宣称AI解释正确率、稳定可靠或超过其他智能体**。确定性结果卡与AI解释分开呈现。

## 完整备份与真实恢复

备份要求单进程服务空闲；有排队/运行仿真、智能体、识别、材料研究、搜索或收件箱分析时409拒绝。复制期间暂拒新API请求（503及Retry-After），结束/异常均释放维护状态。主数据库和LangGraph检查点用SQLite backup API获取一致快照；其余运行文件逐一保留大小和SHA256；原件、失败记录和历史manifest均不改写。

恢复只接受不存在的新目录，拒绝目录穿越、绝对路径、重复条目、清单不符、文件哈希错误及超限展开。中断恢复留下 `.restore-incomplete` 标记，应用拒绝启动该目录，不覆盖现有服务。

本轮原生年计算后完整备份实际恢复：72个文件、10份数据库引用原件、1账号、4项目归属、45记录版本、3仿真任务；启动恢复后的独立应用，用原测试密码重新登录，三份年度结果数值一致，三份HTML报告均可读取。另一个集成测试恢复未完成的LangGraph复核检查点，并在恢复副本完成复核；源运行目录保持未提交。

运维限制：仍是单进程SQLite本地部署，不是多实例高可用。Windows DPAPI密钥需原系统账号；环境变量密钥未包含在归档。校验过程不验证异机密钥、外部EnergyPlus安装或客户灾备RTO/RPO；没有擅自部署公网。

离线恢复命令：

```powershell
.venv/Scripts/python.exe scripts/restore_runtime.py --archive <snapshot.zip> --destination <不存在的新目录>
```

真实计算及恢复复跑：

```powershell
$env:ENERGYPLUS_EXE='F:/EnergyPlusV9-0-1/energyplus.exe'
.venv/Scripts/python.exe scripts/verify_coverage_runtime.py --sources <诊所与Esplanades原件目录> --duplex <原始Duplex.ifc> --output <新的隔离输出目录>
```

机器可读结果见 [results.json](benchmarks/2026-10-25-coverage/results.json)。原始输入、SQLite、完整工具对话、SQL与报告保留于仓库外隔离验收目录，不上传。Honeybee/Ladybug已有AGPL许可边界未改变，闭源商业发行仍需处理。
