## 唯一开发主线与验收出口

**M2：真实文件 → 材料及有依据的数量 → 两方案成本/碳 → 同源报告。**

1. 复用已有成本和生命周期计算器，把已取得的材料层数量接入方案。层包络不能直接当采购量；实体比例、密度、损耗、报价和因子需明确来源，未知不得补造。来源数量由服务派生，用户不能替换成无关联数字。
