# 材料工程量与成本：限定范围交付记录

日期：2026-11-05。基线 main 4720c231eadfe12208b9950892f7d0a414a7b223。采用仓库 VRA-Trust 技能的来源、缺参和失效契约。这里是开发过程验收，非独立机构认证。

## 能力与调用链

材料成本页面 → 六个项目级 material-cost API → Estimate 严格契约 → Decimal 确定性计算 → 不可覆盖记录 → 当前来源核验 → 同源 JSON/HTML。Agent 新增 material_cost_list/read 两个只读工具；不生成报价，不创建清单，不判定最便宜即最优。

- 直接净量、矩形面积、长方体体积；m/cm/mm 尺寸，显式构件数量、合计扣减。几何扣减单位固定 m²/m³。无 CAD 自动算量。
- kg/t、m/cm/mm、m²、m³、件的维度换算；质量与体积必须有密度及来源。损耗未知保留 null，明确无损耗填0；件数逐行向上取整。
- 报价编号、版本、地区、币种、含税口径、有效日期、来源必填。一个清单禁止混币种、混含税口径或报价编号冲突；不自动换汇、算税或加人工机械运输。
- 金额逐行 Decimal HALF_UP 舍入到0.01后汇总，JSON 金额使用字符串。输入仍采用有限范围 JSON 数字，不承诺无限有效位数或任意精度输入；完整小数结果保留，页面数量仅去除尾零。
- 缺数量、损耗、单价、密度或密度来源时，相关金额及总价为空；可读的其他行保留。异常维度、负值、NaN、布尔数字、扣减超过毛量、重复行、过期报价拒绝。
- JSON 导入保留原件并校验格式，随后人工复核再计算。复制形成新的替换情景，原导入件仅作来源，不能声称编辑后的字段与原件完全一致。
- 相同地区、币种、日期、税口径、功能范围及排除费用的2–5份完整当前清单可比较；零基准下降比例为空。功能等效性 NOT_ASSESSED。
- 项目、来源、原件哈希或计算器变化后旧结果 stale，不可进入比较；原记录保留。最大300材料行、每行30个来源；无生产规模性能承诺。

## 独立交叉验证

数据全部为审计构造，报价不是市场价，密度不是实测；测试函数 estimate() 可重新生成相同输入。生产计算用 Decimal，独立答案使用 Fraction 有理数和整数分币舍入，不调用生产算式辅助函数。

## 缺陷闭环

### COST-001：已撤回因子可生成新碳清单（高）

功能：生命周期因子证据。复现：创建来源，绑定因子保存一次；把来源review_state改为rejected；相同输入再次POST lifecycle。预期：409拒绝新清单，旧记录stale。修复前实际：旧记录stale，但新建201。证据：withdrawal-before.log、tests/test_lifecycle.py::test_rejected_factor_evidence_cannot_support_new_inventory。修复：保存及读取双重检查rejected，专项通过；保留原清单，不回写历史哈希。建议：所有新增来源消费模块沿用撤证拒绝契约。

### COST-002：已撤回导热来源可生成新热工结果（高）

功能：热工层材料来源。复现：保存来源绑定的墙体，将来源拒绝，再提交同一墙体。预期409拒绝；修复前实际201。证据：thermal-withdrawal-before.log及tests/test_thermal.py新增撤证回归。修复：新计算拒绝rejected，读取保守失效；最终热工20项通过。建议：不把证据存在等同于证据可用。

### COST-003：打印表格净量/用量缺单位，缺参显示None（中）

功能：新增成本HTML报告。复现：导入三种不同计量单位的清单，保存并打开打印报告；缺密度时查看计价数量。预期每个数量都有单位，未知显示—。修复前实际：净量4.000000000、用量4.20000000000没有单位；缺参拼接None t。证据：ui-report-before.json、report-before.log失败记录、test_report_keeps_quantity_units_and_unknown_values。修复：数量连同原单位展示，空值显示—，页面/打印去尾零而不改原始结果。最终浏览器显示4 m3、4.2 m3、10.08 t，报告回归通过。
