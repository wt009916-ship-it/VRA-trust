# IFC 网格交付前的拓扑与壳关系核验

本批应用源码为 `7496491f998145fb02de2b32517739955b8bb1f4`，对应 PR #43。解决单一构件网格中“边配对闭合，但有自交、壳重叠或错误嵌套方向”仍可产生体积的问题。原来的输出已注明近似量和未检查范围；本次增加实际阻断，不能把历史输出描述为已认证净量。

## 实现及调用链

认证上传 → 保留原件与 SHA-256 → `cad.py` → 经过文件、网络和资源隔离的 `cad_worker.py` → `ifc_geometry.mesh_measurements` → `mesh_topology.validate` → 保存带解析器版本的回执 → 构件明细/JSON。`mesh_topology.py` 同时进入运行时快照与解析器版本；旧记录因解析器改变而失效，不改写原记录。

部署影响：共享隔离运行时文件参与三个解析器的版本身份，所以本次更新也会保守地使既有OCR/规范PDF解析记录失效，需要重新读取；原件和旧结果仍保留。未改变物理核心及天气输入验证，本批不要求重跑年度EnergyPlus参考结果。

保留原有开边、重复面、零面积面和相反边方向检查，再检查：

- 每个顶点周围的面必须是单个连通环，拒绝只在一点粘连的壳。
- BVH 包围盒筛选候选三角面，使用有理数检查面接触。仅允许原索引共享顶点或边范围内的接触；自交、壳间相交、非相邻相切均拒绝。相同坐标精确合并，不按容差缩小间隙。
- 对通过接触检查的各连通壳，用精确射线奇偶判定包含关系。射线命中边/顶点则换方向，八个方向仍有歧义时返回未核验。
- 最外层方向须一致，内壳按深度交替方向；整体反向仍可得到同一绝对体积。不同外壳方向相反、内壳方向不匹配不能用绝对值掩盖。

所有精确谓词只针对输入的二进制浮点三角网格，不代表原生曲面是精确实体。体积数值仍为平移后的浮点四面体积分。此实现未使用 CGAL；其[多边形网格处理文档](https://doc.cgal.org/6.1/Polygon_mesh_processing/index.html)作为区分流形、相交、定向和体积前提的技术参考。

每文件共享预算：120000 个三角面候选对、500000 个 BVH 节点对、120000 次射线/三角面测试；每构件最多128壳。耗尽后体积为 `null`，不会默认为0或延用前一构件成功状态。原有文件、网格、输出、20秒CPU和30秒执行限制不变。只返回首个几何拒绝见证，不声称完整枚举全部错误。

表面积始终是三角面之和，即使体积拒绝也不能把它当并集面积。界面明确分离体积、诊断有向积分与模型声明数量。不修补、不进行跨构件布尔合并、不推断材料净用量或计价扣减。

## 独立答案和实际文件

28项几何测试覆盖分离盒体、整体反向、相反方向外壳、重叠/面边点接触、错误内壳、空腔和岛体、单壳自交、尺度和远坐标、`2^-40`真实间隙、斜棱柱、凹形L棱柱、环体孔内独立实体，以及预算与BVH穷举对照。

独立结果包括：3×3×3外壳减1×1×1空腔为26 m³；4³−2³+1³岛体为57 m³；L形截面面积3、周长8、高1，体积3 m³、表面积14 m²；离散环体采用截面正多边形面积与环向扫掠公式核对，不调用产品积分生成答案。

另5项原生/API测试实际生成 `IfcTriangulatedFaceSet` 文件，上传并进入隔离解析器。分离实体2 m³、正确空腔26 m³；重叠和错误内壳返回未知。原件字节、来源哈希、历史返回及新助手版本绑定均检查。既有25项IFC测试继续覆盖单位、开洞、映射、位置、声明冲突与历史失效。首次组合56项通过，增加凹形/环体后28项几何测试单独通过；最终全量记录另列，不能把这两次当同一次运行。

公开参考继续使用 BSI (2020), *Duplex Apartment Test Files*, buildingSMART International，CC BY 4.0；固定源及归属见[首次IFC交付](IFC_GEOMETRY_DELIVERY.md)。SHA-256 为 `b347a2c8aa8fff6db896a4417a9c50c22ac0ccd7c5cfc22b99b8d29336c606ed`，原文件没有修改。

实际读取295产品，172取得经过本次检查的近似体积，114为部分网格，9无Body。114中69属于既有缺口，新增41个面接触/相交拒绝、4个顶点邻域拒绝。**172不是172项复杂体积独立验收通过。**原独立STEP/Decimal脚本的108棱柱体积及面积、21声明面积、295空间关系仍全部匹配。

拒绝意味着本方法的体积交付前提未满足，不等于原IFC语法非法或建筑设计错误。组装构件可能有意包含相接或重叠子实体，需要另行定义并集与工程计量语义；本批不擅自改动这些构件。

新增45个拒绝项全部有独立见证：另行编写的脚本用精确Cramer线性方程求边/三角面交点、投影边相交核对，或使用顶点链图判断不连通，不导入产品几何谓词。公开[复算数据与见证](benchmarks/IFC_TOPOLOGY_20261107_RESULTS.json)保留三角面、交点或邻域依据。这证明被报告的首个问题确实存在，不证明已经找出模型全部问题。

## 浏览器与性能边界

冻结源码、单独构建、私有数据库和新隔离账号。真实上传正确空腔、重叠壳、错误内壳及公开Duplex四个文件。正确空腔显示26 m³；两个拒绝文件显示“体积 —”，原件下载SHA和JSON一致；错误内壳的诊断积分显示方向冲突。公开模型选择门构件 #6652，显示拒绝原因及网格面索引18、67。页面脚本异常0，本次浏览器操作脚本无失败。

前端71项测试、lint和构建通过；Three.js既有分包体积提示保留。截图仍能看到字号偏小、说明密集，整体体验改版未完成。本批未做新的模型推理测试，不能宣称Agent能力提升。

公开模型两次完整工作流约25.85/26.89秒，隔离执行分别15.81/17.06秒，准备分别7.27/7.31秒。第二次使用共享边局部精确判定以减少裁剪，几何回执逐项相等，但**这两次观测没有证明性能提升**；准备为冷缓存，第二次还与局部测试有时间重叠。30秒限制针对隔离执行，不是整段API工作流。复杂文件仍可能耗尽资源，必须拒绝并保留原件；未用提高上限掩盖失败。
