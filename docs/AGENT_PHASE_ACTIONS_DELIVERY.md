## 实际实现

一般open_ended任务使用模型选择的JSON动作。固定本地模型由JSON Schema约束生成，服务端再次验证完整参数；云端采用JSON object加相同服务端验证，真实云端未验收。无效动作、未开放工具、额外字段、重复JSON键和非有限数值被拒绝，没有静默退回自由文本。保留公开原始响应及控制器转换后的调用；不保存隐藏推理。转换调用编号不表示伪造执行，每个模型选定动作仍走原业务工具和权限核验。其他结构化inspect目标仍用原协议，不能声称全产品协议全部替换。

professional_deliver在开放任务中只接受kind、record_id、record_hash、fact_keys、finish。模型选择本轮实际读到的事实，应用复制来源的数值、单位、期间、年份、载体、面积和无定义状态，再重新读取当前来源。目录不构成数值回执，旧读回执和撤销来源不能恢复旧数值。显式指标及已冻结模型计划限制可选范围；没有计划的自由问题仍可能选错合法字段，来源正确不等于问题理解正确。

requested_defer表示模型不确定，保留未完成和已知缺口；不证明资料不存在或应用不支持。显式勾选项不能被它丢弃。拒绝后的错误返回不会再引发finish异常；一般任务明确澄清后结束为未完成，未解决读取目标不消失。纯状态解释只开放来源审查，不再提供执行时必被拒的数值交付或数值限制入口。
