# 图纸处理、坐标追溯与尺度核验交付

2026-11-07。本批实现原件保全、有限纠偏/过滤、原图与处理图的坐标转换，以及用户声明尺度的一致性核验。没有实现墙体语义修复、缺失尺寸恢复、完整构件识别或净工程量。开发复评仍为 **76/100**；测试数量不折算为专业能力分。GitHub和原型发布以本批`release-receipt.json`为准。

## 实现与边界

`drawing-ui.js → /projects/{id}/drawings → Drawings → 隔离drawing worker → drawing_processing`实际处理上传文件。规范化原图、处理图及可选过滤差异图分别保存并校验摘要。原件不覆盖，新请求产生新记录；备份完整性检查覆盖新派生件。PDF页光栅化/EXIF归一化后的像素不是原PDF矢量或工程坐标。

自动方向采用有界Hough线段一致性；不足、冲突或越界保持原方向，支持率不作为正确概率。手动旋转限定±15°，扩展画布先检查尺寸预算。中值过滤须明确勾选，显示改变像素和暗像素增减；它可能删掉细线，差异图不证明语义保真。六参数正逆矩阵记录坐标映射，OCR候选回溯原图，但不把文字框称为建筑构件。

`drawing-geometry-ui.js → /drawings/{id}/scales → DrawingScales`校验参考尺寸、mm/cm/m、点位和声明误差。至少两条不重复参考区间相交后，才在用户声明的同页等比假设下给出条件尺度；单条/冲突/失效返回空值。长度JSON包含实际输入、尺度记录摘要、算法摘要、图页依据和区间边界。区间仅包含标定尺度误差，不包含本次测量点位、畸变或原尺寸错误；不能作为工程量、测绘或认证。

来源/派生图/算法变化使尺度失效；纯OCR转录复核不改变原像素几何依据。历史保留，不能改写旧摘要消除失效。输入变更、计算失败或较早响应迟到时撤下旧长度，切换尺度后禁用无效换算。

## 实际验证

- 独立金标准先冻结：10个合成图、2个公开图处理场景，两平台分别真实认证API和原生隔离OCR执行。各12个场景通过限定功能检查，不等于所有文字、构件均识别正确。[交叉验证](DRAWING_GEOMETRY_CROSSCHECK.md)给出独立答案、误差限和公开OCR失败。
- Windows最终候选`6bddc12`：1083通过、25平台限定跳过、2警告、6子测试通过，1112.06秒。Linux候选`27af5fd`：1092通过、16跳过、2警告、6子测试通过，678.17秒。Linux与最终候选全部后端/测试/计算脚本字节相同，仅前端过期长度显示及阶段文档随后修改；不冒称Linux已运行后来的前端。前端85通过、构建与Ruff通过。
- 本批物理核心摘要未变。全年三方案原生参考经逐文件摘要和`read_validated`复核后复用上一批结果，没有把复用说成新跑年度仿真。
- 实际浏览器：上传3.25°图、纠偏回执、mm/m尺度、50px→3m与JSON下载、矛盾参考拒绝、手动−2°及显式过滤新版本、原件下载摘要、旧记录保留通过。故意损坏隔离派生图后，尺度`result=null`、按钮禁用，重读图纸撤下几何界面；原件和数据库历史不改。
- DG-004先复现409后旧3m仍显示，再修复并复验。真实API响应在浏览器传输层被延迟，编辑输入后旧响应不再显示；没有替换实际计算结果。
- 390px视口文档宽390px；原图四分之一点期望(260,189)，实际(258.531,187.887)，误差在预设2px交互容差内。导航为横向滚动区域，其屏外按钮不是文档整体溢出。**截图均超时，桌面截图通道返回应用审批超时，因此视觉舒适度和遮挡仍待验证。**
- 浏览器控制台有匿名401、favicon404、预设越界409及重启时连接失败，不能宣称零错误。没有本批真实LLM任务，不加Agent分。
