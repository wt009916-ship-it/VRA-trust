# 同模型时间步敏感性检查交付

基于PR67的78分候选，本批实现同模型时间步副本→已有证据审查→真实全年运行→全逐时差异比较→报告及失效撤回。未合并、未更新正式原型，当前精确提交CI待收口。没有宣称修复EnergyPlus所有粗步长精度或完成实楼校准；评分暂保持候选78、正式76。

## 实际业务路径

仿真页新增“时间步敏感性检查”折叠区。选择原始IDF和每小时步数下载副本，仅替换唯一Timestep数值，保持其他原文/注释/BOM/编码不变；不改原件，不自动登记或确认。通过已有资料入口把原模型和最多两份副本分别审查为baseline/R1/R2并真实运行，建议独立检查项目，避免把时间步变化当节能改造。选择2或3个成功运行，填写用途及四个阈值，创建检查；没有预填“规范限值”。

GET `/api/projects/{project_id}/files/{file_id}/timestep.idf`核对归属/当前原文件SHA、2MiB及唯一受支持IDF9.0时间步。POST `/api/projects/{project_id}/timestep-studies`沿用会话/CSRF/项目边界。记录只追加、绑定实际运行、模型/SQL/天气/引擎/IDD/代码，GET及HTML报告每次重新检查有效性，撤证后summary=null。只比较物理来源；不把碳因子变动当温度差。

`extensions → timestep_studies.Studies → timestep_check.source/compare`重用既有原生逐时及理想系统验证。已有项目执行链为全年运行，接口默认选全年环境；设计日是独立算例及底层比较器验证范围，没有声称新增任意设计日项目执行器。

## 判断规则及边界

- 除Timestep数值外，全部IDF词法字段必须相同；只忽略注释和字段两端空白。天气/引擎/IDD/物理代码相同、所有源运行当前有效才可比较。顺便改材料/算法/设点/日程会拒绝，不能只按面积判断等价。
- 使用真实完整时序，按年月日/小时/DST/区间及环境对齐，不使用SQL TimeIndex数字作跨运行时间身份。逐区温度、显热和同刻汇总分别比较。可选24项理想系统热率及同刻汇总须完整具备原生26变量，不对空气质量流量或其他HVAC给稳定性结论。
- 温度按K绝对差；热率每小时判据为差值≤max(声明W绝对限，较细步长对应小时绝对W×声明相对限)。低于声明近零阈值时停用相对限，相对统计null，不除零。记录超限小时、最大差及时刻、峰值大小/本地样本位移、期间积分差，避免全年抵消掩盖逐时误差。
- 三步长做三对比较，不推断一般收敛阶、Richardson外推、真值精度或推荐“安全”步长。原生小时值包含子步采样约定，差异并不全是积分误差。阈值内只针对声明模型/环境/输出。
- 原生检查沿用64分区/系统、512MiB SQL、完整24/8760/8784时轴及各解析预算；比较SQL只读、60秒查询预算、逐指标有界读取。重计算同时只接受一项，超额429。不是生产容量承诺。
- 界面清空旧数值后重查；输入变化、切项目、迟到响应、请求失败或当前来源失效不能复现旧结果。浏览器用户暂缓，DOM逻辑与构建不是实际点击/视觉验收。

## 新冻结物理算例

几何4×6×3.2m，体积76.8m³、六面112m²；墙R0.7、内外膜0.1/0.04，空气热容研究倍率70。恒边界、周期边界、900W对流脉冲三类，各6/12/60步每小时，共9个新的时间步输入，属于3种物理工况。没有重跑HT/FF旧题当新证据。极干研究边界，无HVAC/太阳/通风/潜热。

独立平衡C(T)dT/dt=UA(T外−T)+Q，C(T)=S/(T+273.15)，分段常值小时的非线性精确解迭代至日首尾差<1e-12K。按声明子步末采样求小时平均以匹配原生输出约定，不是连续小时积分平均。答案、输入及0.02K误差限先冻结：frozen-v1/frozen.json SHA0882c50c3eaed152817a8f360dfa66fbac4f9cb3c29463977fac9b997963ec41；脚本SHA另存，原生数值不参与拟合。

|工况|6步/小时最大误差K|12步/小时|60步/小时|
|---|---:|---:|---:|
|恒定|<1e-12|<1e-12|<1e-12|
|周期边界|0.057384，超限|0.030632，超限|0.008282，通过|
|对流脉冲|0.086304，超限|0.044734，超限|0.010335，通过|

合计5/9达原误差限，4/9超限；干湿前提和零HVAC均核对。失败保留、不改容差。比较器在保留的同一批SQL上检查：恒定工况在声明0.01K差异限内，动态两工况全部三对超限；6与60步最大差0.076413/0.085683K。独立精度与两运行差异是不同判据，不能互相冒充。

## 应用实际验收

真实隔离HTTP流程使用已公开的上一批理想空调年度参考输入做集成，不把它算成新的独立物理基准。三份模型只改6/12/60时间步，全部真实运行8760小时。共209项检查、51个响应通过，服务已关闭；三对各53个指标逐一用独立SQL查询核对最大差、超限小时与积分差。全年度结果在所声明严格阈值下超限，产品如实返回exceeds_declared_threshold。下载原件保全、HTML/JSON同源、撤证清空、重新创建拒绝、跨项目/匿名/CSRF拒绝均留证。未使用模拟LLM或伪造原生结果。

后端33项专项的首次结果为32通过1失败，原因是协议单测把真实设计日投影用在全年默认选择。明确限定测试接缝选择设计日后，仅该项复验通过；实际HTTP独立使用全年，不把接缝替代实际执行。首6项新增前端逻辑及全部202项前端逻辑通过；代码复核后补上旧请求迟到报错隔离，7项专项通过（全量精确版本由CI确认），Ruff/语法/契约导出/构建成功。完整CI另按精确提交记录，跳过不视为通过。

IL-06 PDF同边界3行已用KeepTogether避免跨页拆分。对上一批真实PDF输入重新生成并离线检查第7页：新风冷却标签、三项能量及0.22kW峰值同页可见；原来第6/7页拆分截图保留于PR67证据。不是浏览器验收，不加UX分。

## 重放与证据

`validation/timestep-reliability-20261108/manifest.json`保留原始文件SHA，原生大SQL留本机并由local-raw-sql-index.json记录，排除运行数据库和凭据。安装固定依赖及EnergyPlus9.0.1，设置ENERGYPLUS_EXE，在新输出目录执行：

```text
python -B scripts/verify_timestep_reference.py --inputs validation/timestep-reliability-20261108/frozen-v1 --output NEW_NATIVE_OUTPUT
python -B scripts/verify_timestep_http.py validation/timestep-reliability-20261108 NEW_HTTP_OUTPUT
python -B -m pytest tests/test_timestep_studies.py -q -p no:cacheprovider
```

单元测试原生投影只代表保留SQL回归，不是一次新原生执行。源模型公开参考/自建研究条件不等于实楼；窗口太阳、一般湿热耦合、多区流动、设备容量、工程规范与实楼校准仍需独立验收。当前仍78，不把质量检查工具本身当成所有被检查模型已经正确，也不以局部交付代替95+目标。
