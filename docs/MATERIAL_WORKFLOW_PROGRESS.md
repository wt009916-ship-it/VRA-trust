# 材料工程流程：当前实现与验收（2026-11-08）

限定单个直线墙构件的文件→材料层→显式实物映射→两方案材料成本/生产碳→报告已通过真实公开IFC接口和浏览器任务。该结果不代表多构件专业净量、完整改造节能比较、完整LCA或商业报价核证；M2原始广泛验收仍未全部完成，本批不自行加分。原型18772仍未更新。

## 用户新增能完成的任务

在CAD/BIM页上传IFC，选择墙构件，实际扣洞并按材料层平面切分，保留原材料关系及单位来源。以计量回执建立两套方案：显式填写实体比例、损耗、必要密度、价格和排放因子及来源。数量由服务器从计量记录派生，不能用客户端输入替换；未映射或重复层拒绝，排除层须在两方案共有范围内明示。

成本复用material_cost.calculate，碳复用lifecycle.calculate。界面目前明确限定材料生产阶段；后端支持其他明确活动，但尚未进行五阶段完整用户任务验收。缺比例/损耗/必要密度/价格/因子时完整比较不可用；同因子ID不同版本、价格日期/地区冲突拒绝。单位面积分母是当前项目建筑面积，非所选墙面积。替换材料功能等效、结构/耐火/热工效果不自动判定。

记录同时绑定原文件、IFC读取、分层计量、项目修订、声明证据与计算器版本。来源失效撤下结果，历史不重写。JSON保留原精度，HTML提供逐层数量/费用/碳及来源。新增保存方案历史入口，打开报告重新核验。
