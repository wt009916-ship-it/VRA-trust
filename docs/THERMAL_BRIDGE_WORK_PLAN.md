# 下一批：二维稳态导热能力

2026-11-14。只作为开发安排，尚未实现或验收，不加分。

代码检查：`backend/thermal.py`、Agent能力目录和专业结果范围均明确只支持一维均匀材料层，不含热桥；未发现活动二维导热求解器。这对应原A02/A03的非均匀构造扩展，不重做现有逐层R/U，也不再细化已完成的Agent字段协议。

本批拟交付：明确尺寸、材料分区与导热系数、各边温度/表面换热/绝热条件的二维截面计算，输出温度场、按单位延伸长度的边界热流和热平衡，以及网格与迭代状态。结果是声明工况下的数值计算，不自动补出材料、承重关系、全年节能率或合规结论。

实施顺序：

1. 冻结独立解析基准和工程公开参考，明确坐标、单位、边界、比较点、容差；先于求解器调试。
2. 建立有界、按材料界面分割的网格和能量守恒求解；内部迭代收敛与网格离散误差分开。
3. 验证均质平板、串联层、并联材料、一致温度、反向温差、二维解析温度场，以及零导热/负尺寸/无温度锚点等拒绝情形。
4. 加入公开复合截面交叉验证；只有解析温度场通过不能声称整个热桥方法符合标准。
5. 通过独立核验后接入已有来源、版本失效、API、报告和有限输入界面；浏览器验收保留待用户开启，不绕过。

公开方法依据：

- [ISO 10211官方概述](https://www.iso.org/standard/65710.html)描述二维/三维模型的热流、表面温度及边界要求，并给出恒定物性、无内部热源假设。本批不复制标准全文，不把开发验证称作认证。
- [Fraunhofer WUFI公开两维基准](https://wufi.de/en/two-dimensional-test-cases-of-iso-10211/)给出均质截面温度场和多材复合截面两类检查。采用本项目独立推导的分离变量级数计算均质情形预期值，公开基准仅用于交叉检查其物理设置和误差限。
- [LBL关于误差范数的说明](https://windows.lbl.gov/error-energy-norm-and-isoen-standards)提醒局部误差指标和总体精度不是同一数字；本项目不能将线性方程残差小包装成工程误差已小。

特别边界：相邻固定温度边在角点不连续时可能有热流奇异性。远离角点的温度参考可用于测试，但不能据此宣称总热流随网格收敛。此类情况应明确保留限制，不以放宽迭代容差掩盖。
