# 楼板与板材材料计量交付（2026-11-08）

## 业务变化与范围

多构件材料包络从分层墙扩展到具有明确挤出参考面的 IfcSlab（含屋面板）和 IfcPlate，可与墙混选2–16个构件。同IFC材料实体进行空间并集；跨材料冲突拒绝汇总。单构件材料层、材料集合、JSON/HTML以及已有两套材料成本/碳方案入口均已接通。IfcRoof组合体、梁柱材料计量、任意BRep/映射表示仍不在本批支持范围。

楼板按实际 IfcExtrudedAreaSolid.Position 的参考平面和 AXIS3 分层，不直接套产品局部Z。声明层厚是参考面法向厚度，允许显式方向、偏移和斜挤出；实际开洞网格逐层切割，不按总体积比例分摊。简单挤出及开洞在原参考面坐标中做原生布尔，随后统一刚体变换共享顶点，避免旋转布尔的浮点顶点差异；不容差焊接、不修改原文件、不更换全局几何核验规则。复杂开洞保守走原检查，不能核验则未知。

规则参考：[buildingSMART IfcSlabStandardCase几何使用](https://standards.buildingsmart.org/IFC/RELEASE/IFC4/ADD2_TC1/HTML/schema/ifcsharedbldgelements/lexical/ifcslabstandardcase.htm)、[IfcMaterialLayerSetUsage](https://standards.buildingsmart.org/IFC/RELEASE/IFC4/ADD2_TC1/HTML/schema/ifcmaterialresource/lexical/ifcmateriallayersetusage.htm)。这些资料用于解释参考面；本批测试不构成IFC全标准一致性认证。
