# 内嵌账号与数据库管理后台 · 2026-10-24

`/admin` 现为四页式管理后台。数据库管理从页面直接操作，不再仅显示数据库类型和项目总数。

|页面|实际操作|
|---|---|
|账号与密码 `/admin#accounts`|搜索成员、新增账号、编辑用户名/显示名、重置成员密码、停用/启用、撤销登录和 API 令牌、管理邀请码。右上角修改自己的密码。显示有效会话和项目数量。|
|数据库管理 `/admin#database`|15 个集合的实际记录统计、名称/ID/状态查询、20/50/100 条分页、业务记录详情及历史版本切换；数据库完整性校验、一致性备份、备份列表和下载。|
|AI / API 配置 `/admin#services`|保留模型 API、凭据、视觉模型和连接测试；显示本地 OCR 状态。|
|任务与审计 `/admin#operations`|查询仿真队列、识别任务、收件箱和操作日志。|

集合包含项目、资料文件、证据、建筑模型、材料、识别任务、决策研究、反例搜索、账号、项目归属、仿真任务、审计、登录会话、API 令牌及收件箱。项目与工程资料通过既有业务流程修改，数据库查询页保留只读历史，不直接覆盖证据或历史计算结果。

所有接口仅允许管理员会话访问，项目令牌和普通成员无管理权限；写操作验证 CSRF。新增账号、修改资料、改密、撤销登录和创建备份须再次确认管理员当前密码。错误确认密码返回 403 并在弹窗提示，避免把有效管理员会话误退出。连续失败限流存入数据库。密码采用既有 scrypt 盐化哈希，列表/详情不会返回密码、哈希、盐、会话密钥或令牌值。

重置成员密码与修改用户名会撤销对应账号的会话和 API 令牌，保留原账号 ID 与项目归属。自己改密使用原有换发会话流程。账号资料编辑带旧值校验，避免并发静默覆盖。没有替正式用户设置密码，也没有生成默认管理员密码。

备份通过 SQLite backup API 生成一致快照，完整性检查通过后登记 SHA256、大小及时间；下载时再次校验哈希。备份包含账号凭据哈希和业务索引，需妥善保管；**不是完整部署备份**，不包含上传原文件、服务商密钥等外部文件。页面不执行自动恢复或任意 SQL。

## 实际验证

- 完整后端：205 项 + 6 子测试通过；前端 32 项、Ruff、契约导出、语法与生产构建通过。
- 新增五组后台集成测试覆盖错误管理员密码、CSRF、弱密码/重名、普通成员拒绝、改密撤销会话/令牌、原项目保留、账号编辑冲突、搜索分页、敏感字段过滤、历史版本、数据库校验、备份下载鉴权和篡改拒绝。
- 独立 Edge 与独立测试库：创建 25 个明确标识的测试项目、测试成员、上传文件及两版模型；实际点击账号新增、编辑、密码重置，错误密码纠正后继续提交成功。用重置后的密码在另一浏览器上下文登录成功，普通成员仍不能访问后台。
- 数据库页面实测 20 + 5 条分页、单条名称查询、两版模型切换、完整性检查、备份创建与下载；重新打开浏览器下载的 SQLite，完整性通过，包含 4 个隔离账号和 25 个项目。审计页面包含对应改密和备份操作。
- 390 px 账号与数据库页无页面横向溢出；宽表在内部滚动。完成四个页面切换和最终桌面截图。页面控制台仅记录预期的未登录 401、错误管理员密码 403，未发现脚本异常。
- 本机正式升级前另行创建一致性备份；原有管理员账号、密码哈希、4 个项目与归属逐行核对。验收数据和数据库未加入 Git。

三维、EnergyPlus 与热工核心未修改，先前的公开样本计算证据仍按既有指纹校验。
