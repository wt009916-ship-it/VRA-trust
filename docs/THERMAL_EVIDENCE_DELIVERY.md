本批直接修改原型，接续 PR #4。用户确认暂时没有实楼数据，继续采用公开参考模型与独立构造的算术反例。原始审计评分与历史失败记录保持不变；本报告不构成满分复评。

## 完成的业务链

- 项目 → 热工计算 → 1–40 个材料层 → 明确的表面热阻/适用条件 → 逐层 R、总 R、U → 不可覆盖的独立记录 → JSON/可打印 HTML。
- 厚度 m/cm/mm、导热系数 W/(m K)/mW/(m K) 显式换算。设计修正系数须说明依据；没有自动预测含湿、老化影响。
- 缺少参数保留 null 和缺口清单；负厚度、零导热系数、布尔数值、数值字符串、NaN、超出支持范围、错单位和同名材料矛盾拒绝进入计算。
- 仅比较相同表面热阻、依据和适用条件下的当前有效记录。输出 U 变化比例，不冒充全年节能率或最优改造建议。
- 记录绑定项目版本、材料证据版本、文件哈希和计算器源码版本。证据撤回、文件篡改、计算器变化导致当前结果不可用；原始记录不被改写。
- 运行碳因子新增发布机构、文档版本、数据年份。来源状态独立于数值计算有效性：假设情景 / 用户声明 / 人工复核 / 复核失效。复核必须有本项目内已确认的实际文件和说明，复核者由服务端登录会话记录。
- 来源状态同步进入碳结果、依赖节点、PDF及界面。人工核对来源不等于第三方核证，也不证明碳资产资格。
