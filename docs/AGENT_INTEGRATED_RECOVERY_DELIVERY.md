## 实现依据

`agent_schema_sharing.py`只共享完全相同的大型数组选择契约；展开后与原契约一致，名称、说明、枚举和约束不丢失。含独立JSON Schema标识符的契约不移动。实际原失败请求从18668降到14984输入tokens，在原16K服务中HTTP200；此单请求回放不等于整题通过。

随后整题发现下一请求16787tokens再次溢出，原因是两个工具结果重复发送77项完整能耗目录。`agent_context_sharing.py`仅将完全相同的后续目录改为前一工具消息的ID、JSON Pointer、哈希与条数引用；首份目录、全部唯一事实、所选数值、单位和来源上下文保留，原工具审计不变。独立展开测试逐项还原原消息JSON；不存在截断证据或用摘要替换唯一数据。

`professional_finish`是流程退出请求，不能认证问题已完整理解。每次仍检查声明目标、已选读取、空目录和未执行授权计划，并最终复核来源。`requested_defer`可说明当前权限缺失或缺少已授权参数计划，原因必须与本轮实际参数一致，历史权限不继承。已提交但全部未授权的计划也有明确出口。

自由任务对外项目ID和不存在ID返回相同的当前项目不可用信息，不读取外项目工程结果；随后通过当前项目目录真实核验缺失。直接读取/交付API、明确声明的越界任务目标仍拒绝。没有跨项目值泄露或绕过写权限的观察。
