# Agent任务协议、有限历史与失败恢复 · 2026-11-04

接续已合并的热工PR #5。本批完成可验证的执行基础设施；真实在线Provider模型的任务成功率、自然语言理解和提示注入抵抗率仍待联网验收。协议夹具不会计入真实模型成绩。

## 任务验收规则

界面明确选择目标，服务端依据当前工具结果判定：

|目标|通过条件|不表示什么|
|---|---|---|
|自由提问|始终not_assessed，不接受模型自称完成|不保证任意专业任务已完成|
|检查当前资料与准入|完成当前Evidence Gate读取，记录缺口|检查完成不等于资料通过准入|
|核验已有仿真结果|所选/任务启动时最近运行当前succeeded且有核验指标|不自动提交新仿真，不判定结构安全/节能合规|

任务记录保留结构化目标、目标run_id、验证条件、工具失败次数和结果。读取完成后重新检查运行有效性，证据撤回不能沿用历史成功。任务流程状态与目标验收状态分别展示。

## 有限历史与执行约束

- 明确选择延续上轮时，最多引用当前项目最近链上的3轮摘要。每轮保留原问题、任务结论和标记为未核验的模型解释；不将旧数值当作当前值。
- 新增最近20条任务查询和界面历史入口；跨项目历史ID拒绝。历史任务仍可查看，新轮引用快照单独保存。
- 每个工具只接受相关参数。只读工具的格式/校验错误可反馈给Provider纠正，最多2次；错误时间线不删除。
- 未授权计算、未知工具、跨项目运行引用立即拒绝；历史计算授权不自动继承。带副作用工具执行失败不会自动重试，避免不确定状态重复写入。
- 同任务内重复写操作按归一化参数去重，显式默认值与省略默认值视为同一次操作。该机制仅限当前任务；用户在新任务再次授权是新请求。
- Provider响应限制为assistant角色、函数调用形状和每轮最多4次调用；拒绝重复调用ID、非有限JSON及溢出数字。最多5轮，现有事件预算继续生效。
- 发送前检查64,000字符上下文预算，超过时明确失败，不悄悄裁掉证据；这不是模型token预算或无限长文本支持。
- 失败释放并发槽，错误不降级为虚假工程成功。模型解释不进入正式能耗/EUI/碳排字段。
