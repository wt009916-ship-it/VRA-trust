# 原图线段与疑似断点审阅

本批增加可选的原尺寸线段检测、短共线空隙假设、逐条人工保留/拒绝/待定、版本历史及SVG核查层导出。原件保持原字节，过滤和旋转后的OCR预览不作为检测底图；没有填补原图像素，不把线段认作墙体、结构、尺寸或工程量。此项有实际计算、接口和前端实现，浏览器验收仍按用户选择暂缓。

## 实现与边界

原尺寸暗像素连续横竖线直接提取，斜线使用1024像素分块Hough、128像素重叠；预览单独缩至最长1600像素。检测阈值与间隔均以源栅格像素表示，线端点中心加0.5转换为像素边界坐标。没有按图上比例尺推断现实距离。线段至少40像素，短空隙限定2–8像素，且不得穿过OCR文字候选排除区。

最多4096个原始候选、256条保留线、100个空隙；预算触发会显式标记不完整。支持率是暗像素比例，正确概率仍为null。人工保留仅表示保留几何假设，engineering_validated始终false。来源、解析版本或衍生图变化会撤下结果与审阅，不能导出当前核查层。

新接口为项目下POST `drawings/{id}/line-review`和GET `drawings/{id}/line-overlay.svg`。前者沿用身份、项目归属、CSRF和expected_revision；后者为附件、no-store、nosniff、无脚本CSP。导出嵌入缩略图及来源/记录摘要、审阅版本、截断状态，不提供隐含外部资源链接。小图导出至少640像素宽，避免说明文字被裁掉。

## 缺陷与处理

### DRAW-LINE-01：旧图短线漏检，所测回归已修复

- 功能/描述：缩略检测会丢失短线；概率Hough在原尺寸上也可漏掉连续轴向画线。
- 复现：原公开图启用line_analysis；固定S05/S06。诊断同时检查原尺寸/缩略图暗像素支持及OCR遮罩。
- 预期：4像素容差内覆盖至少0.7；实际首测两处均0，原尺寸Hough单独只恢复S06。
- 严重程度：中。不能作为完整构件缺失依据。
- 证据：validation/drawing-linework-20261116/public-api-v1、short-line-diagnosis.json、original-regression-v2。
- 修复：原尺寸连续轴向提取与分块Hough，原参照8/8；该结果只关闭所测漏检，不关闭所有短线场景。

### DRAW-LINE-02：复杂页候选截断，开放

- 功能/描述：全页候选超256时，未覆盖的短线可能无法进入核查层。
- 复现：冻结的Tudor图启用line_analysis，观察S07和truncated。
- 预期：完整页审阅需覆盖该已建立参照，或提供可继续查看遗漏区域的流程。
- 实际：S07覆盖0，256条上限已显式报告；当前没有分区继续检测入口。尚未单独证明该漏检仅由上限造成。
- 严重程度：中，能力缺口；未将截断结果标为完整。
- 证据：holdout-tudor-v2/receipt.json及response.json.gz。
- 修复建议：提供来源绑定的区域续查与覆盖图，并以新增区域真值验收；不直接取消预算或只按旧图增加上限。

### DRAW-EXPORT-01：导出未提示截断，已修复

- 功能/描述：界面有不完整提示，初版SVG标题和metadata未保留该信息。
- 复现：导出Tudor截断记录。
- 预期：导出同样显式保留不完整状态；初版实际缺失。
- 严重程度：中，可能误读导出覆盖范围。
- 证据：原导出hash保留于公共回执；export-coverage-recheck.json核对三份真实记录的新导出。
- 修复：metadata保留状态/截断/数量，截断时标题显示“结果截断，不完整”，原记录未改。

### REF-LINE-01：新图一半预选区域未建立参照，待补验证

- 功能：测试数据质量，不属于软件检出失败。
- 复现：运行前按prepare_holdouts.py，对冻结ROI计算灰度<80的独立线投影。
- 预期：参照支持率至少0.7；实际Meeting/Tudor各4处不满足。
- 严重程度：中，限制外部验收强度。
- 证据：两份新图frozen.json，已建立标志在调用应用前固定。
- 修复建议：后续建立经过人工复核的斜线、淡线和退化图真值；保留本次不足，不能回填本次成绩。
