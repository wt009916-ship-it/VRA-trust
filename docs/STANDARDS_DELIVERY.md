# 规范资料与条款检索批次验收

2026-11-04，feature/standards-evidence。限定范围的来源绑定检索已实现；不是全规范库、自动审图、规范有效性在线认证或扫描OCR。

## 调用链和真实实现

项目内上传原始PDF → standards-preview子进程解析 → 带规范编号/版本/有效日期/来源的条款登记 → 当前账号复核 → standard-queries → 引文、页码、哈希和查询快照。Agent新增只读standards_search工具，共用同一检索服务。在线Provider行为仍待真实服务测试，工具单测不替代它。

文本PDF在指定页检查引文和条款编号，并防止引文越过下一个条款边界。扫描页没有文字层时，只允许明确标注的人工摘录；未复核材料不会被检索采用。登记的发布机构、使用权和有效期来自用户声明，软件没有独立核证它们。原件内联查看支持PDF页码定位，下载/查看字节的SHA256与原件一致。

检索采用确定性中英文词项匹配，不是语义模型。支持跨规范关键词检索及单条精确编号；多条明确编号同时出现时要求分别查询，防止悄悄忽略其中一条。分数仅为匹配排序，不能解释为工程置信度。中文相邻编号、全角字符先标准化。查询日期晚于状态核验日期、废止日期已到、来源损坏、未复核或同编号多个有效版本均不作确定引用。未命中只说明当前索引未找到，不宣称规范不存在。

资料、复核和查询均持久化留痕。撤回复核、资料库新增版本、原件变化或检索器改变会使旧查询失效；旧快照不改写。项目隔离及CSRF沿用已测主API边界。浏览器所有引文和来源元数据按文本转义；网页链接仅接受HTTP(S)，服务端不访问用户提交的URL。

## 公开来源和真实文件

- 发布公告：[住建部公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2021/art_17339_762460.html)。公告列出GB 55015-2021及生效日期。
- 验收原件：[陕西省市场监督管理局公开PDF](https://snamr.shaanxi.gov.cn/sy/ztzl/sbgxhxfpyjhx/bzcx/gjbz/202410/P020250320618912933247.pdf)。188页、14644570字节，SHA256为e2f20031fcf7696c47fd4813a97c378be08c77903a1423e1db27d7454ef68150。
- 真实解析：188页均无文字层，ocr_performed=false。渲染核对封面、目录及PDF第11页（印刷页1）。只登记1.0.3的一处短片段，不分发整份规范作为语料，也不声称全文已建立索引。
- 生效日期依据封面核对；浏览器成功例使用2022-04-01历史日期。没有把2021年发布公告当作2026年的最新有效性核验。
- [pypdf官方提取说明](https://pypdf.readthedocs.io/en/6.21.1/user/extract-text.html)明确文字层提取不等于OCR，产品按此区分。
