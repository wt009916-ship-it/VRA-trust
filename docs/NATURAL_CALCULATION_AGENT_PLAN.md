## 实施顺序与退出条件

1. 冻结新的原始问题、数量/单位独立答案、应澄清/拒绝行为、允许工具与授权范围；含多材料/不同单位/否定项/缺失/矛盾、参数被注入伪指令、混合读取与计算，以及真实澄清续答。不得复用已调试题计未见成功。草案筛查与完整应用任务验收分开；没有实际计算与同源交付不能算任务完成。
2. 先核对缓存4B的实际推理配置。现网关固定enable_thinking=false、temperature0、1400输出token。官方Qwen3-4B说明有思考模式且建议思考时不用贪心；本机缓存llama.cpp b12110实际--help支持reasoning-budget。只据此提出实验假设，不把官方榜单当本应用能力证明。
3. 以同一模型/源码/任务预算固定比较三种配置：现有非思考贪心；非思考采样（temperature0.7、top_p0.8、top_k20、min_p0）；有界思考（temperature0.6、top_p0.95、top_k20、min_p0，思考预算2048、总输出上限4096）。统一16384上下文、固定种子、单并发、禁用自动上下文丢弃及原有120秒/1MiB响应上限。三臂共享同一个新参数草案协议/schema，基线只指现有推理配置；不能把原应用缺少这个功能导致的零完成率冒充推理配置增益。采样两臂各用两个预先冻结的种子，分别记录结果，不能择优挑一次。前两臂保持1400输出。整个配置包同时有采样及资源差异，不能把差异全归因于思考开关；记录实际时间、token及截断。此处参数为先验设计，运行前还须冻结实际请求与种子，不能根据题目结果改值。
4. 参数草案必须有原问题片段/字符位置及量纲，数值由应用重新解析来源并换算；模型不能只交一个无来源浮点数。未知材料性质、缺尺寸、缺荷载组合、未给因子/价格不能默认补齐。按现有计算器校验，未能证明输入一致就澄清；source_verified不等于intent_verified或专业安全认证。
5. 保持真实计算授权边界：只读任务不能创建结果；没有授权时仅提出明确草案，不暗中执行。已授权且全部必要字段清楚的可执行任务不反复要求同一授权。写调用保留幂等/不确定结果不重试及原始来源，计划版本变更需重新绑定，不能悄悄改旧计划。
