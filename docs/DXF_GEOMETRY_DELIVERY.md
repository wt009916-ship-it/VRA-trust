# DXF块展开与几何测量增量

2026-11-05，95+路线工作包4的DXF子批。原67分基线保留，本批不提前增加完整CAD/BIM或图纸能力得分。IFC几何/工程量、OCR、DWG、模型转换、图纸修复和跨专业净工程量尚未完成。

## 实际调用链与边界

认证上传→原件SHA-256→CAD独立子进程→`cad_worker.py`→`dxf_geometry.py`→源句柄/实例路径/几何测量→不可覆盖记录→前端表格和XY投影→原件/JSON下载。解析器版本同时绑定worker和新几何模块哈希，变更后旧记录stale，隐藏旧值。DXF原件没有改写；审计要求修复的文件仍拒绝。

模型空间顶层`counts/objects`保持原口径；`geometry.objects/expanded_counts`单独记录展开后的叶实体，不与顶层数相加。顶层INSERT历史字段`expanded:false`表示它在旧的顶层objects列表内仍未展开，展开结果只在geometry内。实例路径包含源INSERT句柄、块名及阵列行列、子实体句柄；重复零间隔实例也保留，不擅自去重。层0继承插入层，外部参照不访问。

支持嵌套块的基点、OCS、旋转、镜像、非均匀缩放及阵列偏移；LINE、ARC、CIRCLE、ELLIPSE、2D/3D POLYLINE及LWPOLYLINE的限定长度。基本闭合椭圆和已检查简单闭合直线多边形提供边界面积；自交、重复顶点、回折、曲线多边形未核验拓扑、3D多段线和开放边界不伪造面积。宽多段线仅测中心线/边界，不包含线宽面积。

长度使用局部差向量变换，避免大平移后的相减损失；曲线在仿射变换后的两个轴向量上做自适应Simpson积分，区间先细分至≤π/4避免周期采样混叠。误差字段是数值估计，不是严格误差证明。椭圆参数跨度与2π按**绝对容差1e-12 rad、相对容差0**判断完整周；容差以内开口不作独立拓扑证明，该容差也写入结果。坐标仍为双精度。

新增预算：10,000遍历实体、100,000顶点/采样点、16层块嵌套；简单边界最多512点进行精确有理数相交判断；明细缺口最多1,000条并保留总数/截断状态。沿用10 MiB文件、8 MiB结果、30秒子进程超时及2个并发槽。未知实体、外参和面积缺口明确列出。不是OS级硬内存沙箱。

前端展示最多300实体及限定投影，曲线65点采样，保持XY等比例，剔除截断多段线预览；带弧折线不会画成假直线。它不是完整CAD渲染：不表达全部文本、尺寸、线宽、遮挡或图纸空间。几何量不代表建筑/房间面积、材料净用量或结构安全，不自动扣洞、去重叠、识别墙柱。

技术依据：[ezdxf INSERT](https://ezdxf.readthedocs.io/en/stable/blocks/insert.html)、[LWPOLYLINE及OCS/bulge](https://ezdxf.readthedocs.io/en/stable/dxfentities/lwpolyline.html)、[POLYLINE](https://ezdxf.readthedocs.io/en/stable/dxfentities/polyline.html)。同步检查本机固定ezdxf 1.4.5的matrix44/multi_insert实现。应用没有直接依赖会丢掉重合阵列实例的去重行为。

## 独立验收

20项新增几何专项，加原CAD 8项共28项：多级基点、旋转、镜像、各向异性、二维阵列、OCS高程、正负bulge、椭圆与圆弧、3D长度、拓扑反例、缺单位、外参、循环和预算拒绝、版本失效。独立答案采用手工仿射变换、128点Gauss-Legendre积分或100,001点复合梯形积分，不调用产品积分助手生成期望值。

嵌套样例原顶层1个INSERT，展开LINE/LWPOLYLINE/CIRCLE各2。线段起止`(8000,19000,0)→(2000,31000,0)`，长度√180 m；矩形边界36 m²/周长26 m；非均匀变换圆为椭圆，面积1.5π m²、周长约7.932720 m。第二阵列实例沿独立计算方向偏移10 m，源句柄相同但实例路径不同。

公开参考来自[LibreCAD官方建筑库](https://github.com/LibreCAD/LibreCAD/blob/ae1e3b8152a18334109fd93393dcc8dd5e436c3c/librecad/support/library/plan/architect/Bathroom-toilet-E.dxf)，固定提交`ae1e3b8152a18334109fd93393dcc8dd5e436c3c`，9051字节，SHA-256 `49ce8ea9f4c75d50c25229397f21f8e90e84da4a984cbb8505f8873bf9d1e9de`。它是公开卫生器具符号，**不是复杂整栋模型或现场图纸**。仅本地验收，不再分发原文件；引用和哈希保留。GitHub匿名API曾限流，改用公开git引用固定提交，并未绕过权限。

`scripts/verify_dxf_reference.py`独立解读ASCII组码、核对INSUNITS=4，以直线公式、圆弧公式及另一种椭圆积分核对全部12个实体（LINE 6、ARC 4、ELLIPSE 2）；经真实API上传及子进程解析，最终全部一致。完整椭圆4B周长约0.920838008160 m、面积约0.063225 m²。复验：从上述固定链接下载原文件，再执行 `python scripts/verify_dxf_reference.py INPUT_DXF NEW_OUTPUT_DIRECTORY`；哈希不同或未覆盖实体会失败，输出目录不允许覆盖。

真实浏览器在已授权隔离项目上传嵌套样例和公开文件，检查源哈希、路径、6/12实体、36 m²及投影；最终公开记录`cad_8877914d721247f9b347dee73413d1e0`。修复前的公开记录`cad_f8422993a4b148f18c1112c4c8a3d34f`及嵌套记录保留，当前显示stale，旧值隐藏。浏览器控制台无error；工具绑定失效经重新绑定恢复，不算产品故障。
