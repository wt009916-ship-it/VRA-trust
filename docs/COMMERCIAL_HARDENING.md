# 商业化打磨第一批：导入可诊断、结果可核对

日期：2026-10-21。此批完成本地产品可靠性改进，不代表已经满足商业交付、国内节能审查或客户能耗准确度要求。

## 已实现的用户行为

- 默认单文件上限从 20 MB 调至 64 MB，可由 `VRA_MAX_UPLOAD_MB` 配置。浏览器读取服务端实际上限并在传输前拦截超限文件。EPW 解析另保留 20 MB、单气象年的约束。
- 文件写入后须保留至少 64 MB 存储余量。新文件通过临时路径完成写入，登记失败清理本次新文件；不删除历史资料。
- IFC 导入保存完整逐空间诊断：数量、名称、GlobalId、已有几何表示、错误分类、修复动作、原文件哈希。失败记录自动出现在界面，支持鉴权 JSON 下载；来源后来变化时，原始报告仍保留并显示当前来源校验失败。
- 只解析部分空间时仍拒绝采纳整个导入，不使用 Box/FootPrint 或默认层高冒充缺失实体。没有 IfcSpace 的文件也明确阻断。
- 助手增加“天气核对 / 工程诊断”任务。天气工具必定执行，模型只看到相关任务上下文和工具；再次核验来源后生成数值卡。工具完成状态、AI 说明状态、仿真准入分开显示。
- 空数组、JSON 指令、空答复或服务错误不会清空已取得的工具结果；说明异常显示 `partial`。可读文字仍标注未核验，不参与指标计算。模型试图替换用户计算计划仍使任务失败；天气任务即使勾选允许计算，也不能调用仿真工具。
- 结果卡包含站点、记录数、年均温、度日、太阳辐射、单位和 SHA256；缺失数值保持“—”。导入诊断在窄屏采用逐项卡片，避免表格撑宽整个建模区。

## 后续交付门槛

这些是待完成工作，不是已有能力：

1. 模型覆盖：实际门窗、墙层、热区与邻接、复杂/斜面空间和真实 HVAC；用完整国内项目逐项对照人工基准，记录面积、体积、构件和热边界差异。
2. 工程校准：经授权的账单、运行工况、气象和模型建立校准集，预先确定误差指标与验收阈值，再做盲测；现有参考模型不能替代。
3. 运营可靠性：后台任务恢复、备份恢复演练、存储迁移、并发与长任务压力测试、版本升级回滚、权限审计；当前单进程本地部署没有商业 SLA。
4. AI 质量：更合适的模型、结构化输出约束和独立任务评测集。保持工具输出主导，分别统计工具成功、答案覆盖、事实错误与拒绝边界。现有小模型两次成功返回不代表稳定。
5. 客户试用：安装文档、可复现问题包、工程师修正流程和明确适用范围；待获得合法许可再与斯维尔/广联达实机同题比较。原有 AutoGen/LangGraph 结果保持历史记录，本轮未重跑它们。

服务器、公网部署和第二台电脑验收继续按用户决定暂缓。
