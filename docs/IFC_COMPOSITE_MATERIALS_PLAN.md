# 复合梁柱材料空间分区计划

2026-11-15。基于 PR79 的候选源码，先待其精确 CI 收口。原八维 87 场景门槛不变，当前候选 78.5，不承诺局部模块必涨分。

去重：原生单构件几何、层切分、同材并集与成本碳算术已有实现。PR79 只把整材梁柱接入；不同材料仍整体拒绝。此批只补真正的材料几何分区，不重做成本计算或梁受力。

目标：显式 IfcMaterialProfileSet 中每个材料轮廓对应到同一实际扫掠体的 IfcCompositeProfileDef 子轮廓；逐材原生生成、保留原开洞/截切/放置，再检查各实体和空间并集。必须全部轮廓一一覆盖、无异材重叠；不按名字、颜色或面积比例猜分。不支持的变截面或无法映射的布尔结构保留拒绝。原文件不修改，克隆仅为几何计算。

冻结独立参照后实现：相邻两个矩形截面、单侧开洞、跨材开洞、嵌套空心套筒与内芯、重叠冲突；米/毫米、刚体放置和映射。原生三角化误差阈值不得在看结果后放宽。覆盖匹配、材料缺失、错轮廓、多次引用及深度/数量预算均应拒绝。逐材来源 ID 必须进入原有多构件、两方案与报告链，异材冲突不能部分交付。

顺序：有界内核实现与独立算术→原生隔离/API/成本碳/撤证→前端适用范围与构建→精确 CI→证据复评。浏览器按用户选择暂缓；不合并 main、不更新正式数据、不扩大训练。

参考：buildingSMART IFC4 ADD2 TC1 的 IfcBeam、IfcMaterialProfileSet/Usage，及 IfcOpenShell 官方 geometry_processing。模型声明来源不等于工程认证。本批构件几何若只有合成参照，必须如实标记；不能复用单材公开样本冒称复合实楼验证。
