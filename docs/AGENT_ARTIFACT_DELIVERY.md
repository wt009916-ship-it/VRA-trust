# 材料核验任务产物：2026-11-06

本批新增来源绑定的材料核验目标，使任务交付包含当前有效的清单、数量、金额、方法及来源。流程读取与模型自主调用分别留痕；不能把程序保底读取算作模型自主规划。综合开发复评保持 **73/100**，95+目标仍在执行。

## 实现及使用

Agent目标选择“核验材料清单（默认最新）”。新任务在执行开始时锁定最新清单；延续同类任务时保持原清单，即使后来创建了新记录。API可传 `objective: inspect_material_cost` 与 `target_cost_id: cost_…` 指定记录；界面尚无专门的目标ID选择器。跨项目目标在启动前拒绝，不兼容的目标字段返回422。

该目标只提供项目、清单列表、清单读取三个工具，即使勾选允许计算也不能执行写工具。控制流程在模型调用前读取目标，交付前再核验；完整且有效才为 `verified`，缺参、无记录或失效为 `incomplete`。模型服务不可用仍为失败，无成功降级。此任务不要求能耗模型IDF/EPW。

结果卡直接使用已有材料计算器的当前核验结果。面积等连续量按净量×(1+损耗率)，件数按同一公式逐行向上取整；金额按计价数量×单价逐行HALF_UP保留两位再相加。保留十进制字符串、计量/计价单位、价格来源/版本/有效期、声明范围和排除项。密度字段保留在产物中，完整详情可查看同源HTML报告；结果卡并非全部单位转换过程的解释器。

模型自由文字以 `audit_only` 保留在认证后的完整任务API记录中，不用于结果卡或后续材料任务摘要；没有新增查看模型原文的专用界面。不是语义纠错模型，也没有证明模型解释本身可靠。其他开放问答仍采用既有路径。

读取已完成的材料任务或历史列表时重新校验清单；当前来源/版本失效则隐藏旧数值，原持久化任务和时间线不被重写。时间线属于当时的审计快照，当前结果卡属于本次重新核验。完整任务返回核验时间及历史完成状态。
