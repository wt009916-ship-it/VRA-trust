# 设计气象来源核对交付

本批新增 DDY 原件登记、来源声明与版本、人工复核及撤回、模型设计日显式映射、逐字段差异、同源 JSON / HTML 报告。开发侧复评仍为 **76/100**，95+ 目标未达，不扩大训练，整体视觉改版仍按原顺序后置。

## 实现与边界

- 仿真页“设计气象来源核对”连接真实上传、持久化和模型文件读取。使用严格 IDF 9.0 字段布局，UTF-8 / Windows-1252 显式选择；DDY 最大 2 MiB、模型 32 MiB、每文件最多 64 个设计日。不是所有 DDY/IDF 版本通用解析器。
- 每次来源复核保留修订、账号和依据；每个核对记录固定来源/模型/项目修订、文件 SHA-256、对象与行定位、核验器版本。当前读取重新检查依赖，失效返回 result=null，历史存储结果不改写。
- 逐日核对 25 个非名称字段和站点 4 个数值字段；名称由用户明确映射。同名不证明同源，异名可显式核对；空白与显式默认值保守区分；日程同名不证明日程内容一致，其他定容工况保留待验证。
- 发布方、年代、权限和适用范围都是用户声明。人工复核不认证权威、现行规范或实楼适用性；不会改写模型、重新运行物理计算，或替代原生引擎实际采用工况核验。特别是引擎可能依海拔修正气压，字段相同不能证明其实际采用值相同。
- 来源 32 条 / 项目、核对 128 条 / 项目；写入前在事务内复查依赖，避免比较中撤证后仍保存有效结果。来源网页仅作为元数据保存，不在服务器请求该地址。

## 新运行证据

Windows **1145 通过 / 31 跳过**，Linux 非 root **1154 通过 / 22 跳过**，均 6 个子测试通过、2 个既有依赖警告。每平台 6 个年度参考依赖检查因本候选未重跑年度参考而跳过；其余主要为另一操作系统专用检查，详完整日志。物理计算源码哈希未变，不把上一批年度验收计作本批新测试。

32 项设计来源专项、94 项前端测试、后端 Ruff、前端全源码语法与构建通过；保留 Three.js 大分块提示。完整 API 契约已更新。双平台 5 个公开站点 / 90 个设计日，独立逐行读取器核对 2365 个原始字段；5 个异名模型与 5 个风速变化反例均符合预期，双方回执一致。详 [交叉验证](DESIGN_INPUTS_CROSSCHECK.md)。

真实浏览器完成登记 / 复核 / 映射 / 核对 / JSON 和 HTML 读取；两个设计日共 50 个字段一致、改变映射清空旧结果。迟到刷新竞态修复后通过故意延迟响应复测；390px 页面无横向溢出（表格折叠状态）。外部撤回来源后正在打开的结果自动消失、API stale/null、HTML 撤下结果；原 DDY 下载字节哈希不变。原件/来源/结果/报告共 4 个地址匿名均 401、另一账号均 404，缺 CSRF 写入 403。普通点击本次通过，截图仍超时，不能计视觉验收通过。

原型的 174 条 records、3 条 jobs、参考索引及用户未提交 SKILL.md 编辑均通过哈希保全检查。D 盘不足 1 MiB，源码和验收在 C 盘完成；发布使用独立 C 盘 Git 工作副本，原 D 盘 checkout 不强行更新。发布、CI 和原型切换另以本批 release-receipt.json 为准。
