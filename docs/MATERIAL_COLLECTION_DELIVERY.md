# 多墙材料包络去重：候选应用交付

用户现在可在候选应用的CAD/BIM页，选择同一IFC内2–16面直线分层墙，得到按IFC材料实体分组、扣除同材料空间重复的包络体积，并打开同源报告/JSON。不同材料占用同一空间时拒绝汇总；缺一面墙的有效层几何也不把其余墙当完整结果。原型5209d744未更新，开发证据复评75不变，完整CI待本提交检查。

## 实现和边界

复用现有真实洞口网格切层，在共同坐标系中按材料实体ID做Mesh64布尔并集，独立边界积分检查输出拓扑和体积。共同大坐标平移在组合局部变换前消去。材料层总预算256、输入/单次并集输出三角形40000，并沿用进程隔离和OS资源限制；不是无限模型支持。材料同名不自动合并；不同材料的并集和与整体并集不一致、超过固定容差时返回归属未解决，不分摊、不保留部分总量。

新接口 `/api/projects/{project_id}/ifc-material-collections` 保存独立materialset记录，按项目权限、CSRF、原件摘要和解析版本校验；没有更改数据库表结构。旧单墙方案仍使用takeoff记录，避免把材料去重后的量伪装成某一墙层量。新历史/JSON/HTML都实时重核验，来源失效撤下结果、历史原件不改写。前端复用既有计量状态控制器，扩展材料筛选/16面上限/结果表，保留旧几何并集64构件行为。

本次是材料层包络，**不是采购材料净量**。公开模型的Metal - Stud Layer包含层空间，不能全部换成钢实体。实体率、密度、损耗和材料性能另需来源。直线轴墙以外的板/梁/曲墙、多文件跨模型汇总、专业计量扣减规则、直接接入多构件两方案成本/碳仍未完成；H01/H02保持部分，不因为新增入口加分。
