# 梁分析辅助：实现与独立验证进展

2026-11-05。分支feature/beam-analysis，基于main 688f519。后端、界面及限定浏览器闭环已验收，增量复评65分（详RESCORE_20261105.md）；远程CI及合并记录另行追加。本批不代表结构设计软件或结构安全认证。

## 实际范围和调用链

梁分析表单 → POST beam-analyses → BeamInput严格校验及SI单位换算 → 分段线弹性梁计算 → 保存不可覆盖记录与来源快照 → JSON/HTML/历史记录。Agent新增只读beam_analysis_list和beam_analysis_read，调用同一来源有效性检查，不允许模型自行创建荷载计算。

支持左铰右滚支的简支梁、左端固定的悬臂梁；恒定EI矩形截面；向下集中力、分段均布荷载及叠加。输入包括几何/材料/荷载来源、支承假设和可选项目证据。兼容m/cm/mm、Pa/MPa/GPa、N/kN、N/m/kN/m/N/mm。没有自重自动加入、材料强度默认值、规范组合系数、图纸荷载自动识别或承载能力结论。

计算支反力、内力、变形、线弹性弯曲应力；剪力分别保留作用点左右值。弯矩极值由区间剪力零点和荷载边界求得；挠度极值由转角求根，不能用图中采样最大值替代。图示是计算结果可视化，纵向放大不是实际变形比例。实现采用正值因式化的Green函数积分，避免近支座的大数相减损失精度。追溯公式中的y向上为正，输出挠度/转角向下为正。

模型筛查使用跨高比10、挠跨比0.05、转角0.1rad作为本工具提示阈值，不冒充规范限值。超过筛查值仅输出带警示的诊断量；所有记录的structural_safety和code_compliance均为NOT_ASSESSED。

## 公式来源与独立方法

[代尔夫特理工大学课程](https://mude.citg.tudelft.nl/workbook-2025/assignments/WS1.3/2-solving-boundary-value-problems.html)提供平衡与Euler–Bernoulli控制方程及简支边界。实现由这些方程及相应支承条件推导，不把课程示例单位直接套用为工程输入。

另一个Purdue课程PDF的直接下载连续遇到TLS中断，未取得本地公式表，故不计作已核实的公式证据。其URL与状态保留在validation/engineering-20261104/source-plan.json。

独立答案采用Fraction有理数闭式解，以及另行组装的Hermite梁单元刚度矩阵/一致荷载有限元求解器。后者不调用生产求解器的单位换算、反力、积分或极值函数。分段与偏心叠加两个支承案例的15个共同位置进行了比较；极近支座另用高精度有理数验证，避免有限元极短单元病态造成误判。

## 缺陷及验收边界

### ENG-001：近固定端荷载导致浮点抵消（已修复）

- 功能：梁挠度及近支座内力。
- 复现：上述6m/200×300mm/30GPa梁改为悬臂，10000N集中力作用在距固定端1e-8m处。
- 预期：自由端挠度2.2222222209876543e-19m。
- 原实际：2.2903636773931985e-18m，约10.3066倍。公式正确仍不能排除数值不稳定。
- 严重度：高，工程计算准确性缺陷；绝对值虽小，不能掩盖数量级误差。
- 证据：near-support-counterexample.json；原始文件不改写。
- 修复：Green函数和正值因式化积分，避免镜像变换丢失原始微小距离；Fraction与有限元分别复验，新增极短荷载区间测试。当前结果2.222222220987655e-19m。

### ENG-002：会话过期后未提交的表单丢失（梁表单已修复，其他表单未扩推）

- 功能：长表单编辑及登录恢复。
- 复现：填写梁表单；会话已过期时提交。
- 预期：提示重新登录并在同一用户安全重认证后恢复草稿，不把资料泄露给其他账号。
- 实际：401转到登录页，未提交表单消失。
- 严重度：中，用户工作丢失风险。
- 证据：浏览器实际操作及ui-server.log的401；未生成对应成功计算的浏览器证据。
- 修复：梁草稿仅在当前页面内存保留15分钟；同账号、同项目、项目及证据版本一致时恢复，刷新或显式退出清除。重认证及项目访问检查成功之前不显示草稿，不自动重提计算。不同账号/证据撤回/版本变更/超时用6项前端测试验证；真实401后同账号重登已两次浏览器验证，保留空值及荷载清单，历史记录没有自动新增。其他长表单恢复另行建设。

### 历史验收环境阻断（已解除，不是产品缺陷）

重新登录本机隔离测试账号thermal_ui_test时，自动审批明确拒绝，理由是无法从当前上下文确认用户对该账号登录的明确授权。用户随后明确授权本次本机隔离测试登录，才通过浏览器继续验收。未绕过拒绝、未用接口登录代替；会话过期测试只把该隔离账号的既有会话设为过期，不修改凭据或扩大权限。当前此阻断已解除。

限定能力仍不包含变截面、框架、剪切变形、扭转、轴向稳定、动力、材料非线性、荷载自动识别或结构安全结论。真实楼宇、材料和专家复核继续待验收。


### ENG-003：全局图标高度压缩工程曲线（已修复）

- 功能：荷载图和内力/挠度曲线。
- 复现：完成简支全跨10kN/m算例，查看结果图。
- 预期：图示按容器宽度保持比例，能看清支承、荷载和变形。
- 原实际：全局svg高度18px，图标级尺寸使图示难以辨认。
- 严重度：中，结果可读性缺陷。
- 证据：beam-result.png（修复前）、beam-result-fixed.png及beam-final.png（修复后）；宽875px时荷载图176.2px、挠度图218.75px。
- 修复：工程SVG显式height:auto，保留viewBox；没有改变计算数据或通过放大曲线冒充真实比例。

### ENG-004：紧贴右支座的极短荷载区间丢失左反力（已修复）

- 功能：简支梁支反力与边界剪力一致性。
- 复现：6m梁，q=10000N/m，区间[5.999999999999999,6]m。
- 预期：按输入浮点数的精确有理表示，RA=q(L-a)²/(2L)=6.573840876841765e-28N，与左端内侧剪力一致。
- 原实际：RA=0，内侧剪力仍为6.573840876841765e-28N。
- 严重度：中，极端数值一致性缺陷；不将其绝对量夸大为实际结构危险。
- 证据：right-support-reaction-counterexample.json及test_one_ulp_patch_at_right_support_preserves_reaction_and_boundary_shear。
- 修复：用两端距支座距离的和计算合力力臂，避免先取中点再做近等数相减；最终全量回归通过。
