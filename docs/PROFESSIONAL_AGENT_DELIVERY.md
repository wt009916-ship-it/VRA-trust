## 实现与使用

项目操作的验收目标增加“核验热工构造”“核验阶段碳清单”。新任务默认锁定执行开始时的最新记录，延续同类任务保持原目标，跨专业延续不会继承另一种记录ID。API分别使用 `inspect_thermal / target_thermal_id`、`inspect_lifecycle / target_lifecycle_id`；界面尚无专门的目标ID选择器。不兼容目标返回422，跨项目目标启动前拒绝。

新增thermal_list/read、lifecycle_list/read，工具总数26→30。专业核验仅提供项目、对应列表/读取三个只读工具，勾选允许计算也不能扩展为写工具。复用Thermal.view和Lifecycle.view，不引入第二套工程计算器。材料任务迁入同一协调机制，旧字段兼容；流程读取与模型自主调用分开记载。模型不可用仍失败，无降级成功。

热工结果保留原单位、归一化值、修正系数与依据、表面热阻、逐层R及总R/U。明确一维稳态范围，全年节能率和合规均未评估。碳结果保留纳入/排除阶段、功能单位、声明面积、评估年限、活动量换算、年量重复倍数、因子来源/发布者/版本/地区/方法。排除不是零排放，清单不是已签发碳信用。

核验完成仅表示指定记录当前完整有效，不证明输入实测、因子权威、清单无遗漏或规范合规。缺参、无记录、来源变化仍为incomplete。查看任务/历史时重新核验；原保存记录不改写。原模型文字保留审计、不进入正式结果或专业任务后续摘要；这不是语义纠错，更不证明模型理解正确。

## 必须保留的模型错误

真实thermal_read把R写成W/(m·K)和W/(m²·K)，而正确量纲是m²·K/W；thermal_continuation还把U写成W/(m·K)。carbon_read把408、7.8、1348.5、1.875这些阶段总量写成每平方米量；false_credit把整个15年期3.53235 kgCO₂e/m²误称为年量。原文完整留在live-primary/live-results.json。正式产物和结果卡使用计算字段及固定单位，不采纳这些错误文字；开放问答的相同风险仍未解决。
