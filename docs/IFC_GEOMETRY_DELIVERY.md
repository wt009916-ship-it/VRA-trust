# IFC声明数量、几何测量与空间关系验收

2026-11-05，工作包4的IFC子批。范围：IFC2X3/IFC4样本的类型/实例单值属性、嵌套声明数量、直接空间父级关系、唯一Body的原生三角化与限定测量。不是完整BIM合规验证、碰撞检查、净工程量计价或实楼认证。

## 调用链与真实实现

认证上传→保留原文件及SHA-256→`cad.py`受限子进程→`cad_worker.py`→`ifc_details.py`声明/单位/关系→`ifc_geometry.py`原生IfcOpenShell转换/网格检查/积分→不可覆盖记录→构件选择器/明细/同源JSON。`parser_version`绑定上述新增模块，更新后旧记录stale且隐藏数值。原有项目授权、CSRF、文件完整性、并发槽及超时规则沿用。

声明与几何分列：模型的NetVolume或Area字段并不是几何独立答案。保留set/属性/数量/类型/关系/owner实体编号、复杂数量路径、公式、计量方法和单位来源。实例覆盖类型时两条来源都保留；重复或多类型冲突标为ambiguous。仅单值属性解释原值，其余复杂属性叶项明确标不支持，不补猜。复杂属性/数量递归最多12层、每产品2000项，环引用拒绝。

数量支持长度、面积、体积、质量、时间和无单位计数。显式单位优先，否则查找相应量纲项目单位；缺AREAUNIT不擅自用长度平方补造。SI前缀按长度幂换算；质量统一kg；转换单位核对量纲及指数、递归检查并拒绝偏置/未知/环引用。不把项目单位冲突当1。原始数量为负或非有限值不能给有效换算量。归一化成功仍标“声明值”。

几何采用固定IfcOpenShell 0.9.0.post1/OpenCASCADE；局部SI坐标测量，原生处理映射/非均匀缩放、位置、开洞，世界米制包围盒用于定位。设置显式保存：world=false、convert-back=false、weld=true、线性细分0.001、角细分0.5、开启开洞扣除。每构件仅一个Body；无Body、多个Body、无位置、无有效长度单位或转换失败保留状态，不默认为成功。

表面积为三角面面积之和；体积采用平移至局部参考点的带符号四面体积分，避免远坐标抵消。只合并严格相同顶点，不按容差修补；每条边须恰好两次且方向相反，重复/退化三角面或开边时volume=null。连通壳分别移原点后保持符号求和，可保留内壳扣减。**闭合边条件并不证明无自交、无重叠、壳嵌套正确或完整流形，输出明确是近似网格量；原生转换警告尚未独立逐项归档。**不做构件总量求和，避免重复计算宿主、洞口、空间或重叠构件。

预算：每文件1..10 MiB，产品≤10000、累计网格顶点≤100000/三角形≤200000，输出≤8 MiB、子进程30秒、2个并发槽。预算在原生转换后检查，尚非硬内存沙箱；不能宣称通过恶意文件资源隔离认证。地图投影转换、完整IFC验证、BRep精确工程量和交付格式转换均未完成。

技术参考：[IfcOpenShell几何处理](https://docs.ifcopenshell.org/ifcopenshell-python/geometry_processing.html)、[几何设置](https://docs.ifcopenshell.org/ifcopenshell/geometry_settings.html)、[单位接口](https://docs.ifcopenshell.org/autoapi/ifcopenshell/util/unit/index.html)。同时检查本机固定版本源码；应用对未知单位自行拒绝，不照搬库的缺省缩放1。

## 独立答案与实际运行

新增25项IFC专项：米/毫米、2×3×4盒体24 m³/52 m²、旋转与世界包围盒、开洞后22 m³/63 m²、映射非均匀放大后的576 m³/488 m²、嵌套位置、远平移、开网格/反向面/重复面/退化面、内壳扣减、缺单位/Body/位置/冲突Body、面积体积前缀、kg、英制转换、错误量纲、未知/环单位、实例覆盖/重复冲突、复杂数量循环、网格预算、API原件/版本失效及空间分解关系。期望值来自基本几何公式及显式单位关系，不调用产品测量助手生成答案。

公开模型为[Duplex Apartment建筑IFC](https://github.com/buildingsmart-community/Community-Sample-Test-Files/tree/31eb1dd0a0406fb9ebf0ebd823b48e1ec95afc08/IFC%202.3.0.1%20%28IFC%202x3%29/Duplex%20Apartment)。固定提交`31eb1dd0a0406fb9ebf0ebd823b48e1ec95afc08`，2,380,763字节，SHA-256 `b347a2c8aa8fff6db896a4417a9c50c22ac0ccd7c5cfc22b99b8d29336c606ed`。署名：BSI (2020) “Duplex Apartment Test Files,” buildingSMART International；CC BY 4.0。本地原件未修改、不随本批代码再次分发。仓库说明样本并非全部通过有效性检查，不能当作官方合规认证样本或实楼实测。

最终真实API+子进程读取：295产品（墙57、门14、窗24、空间21等）；217为闭合网格近似量、69为partial_mesh、9无Body。**这217不是217项独立准确性验收通过**。独立脚本`verify_ifc_reference.py`不调用IfcOpenShell读取期望值，直接解析固定文件ASCII STEP字段，以Decimal复算108个无洞矩形拉伸体的体积和表面积，核对21项声明面积及全部295产品的原始空间关系；均匹配。其余复杂体/曲面没有独立几何答案，明确待验证。脚本针对固定哈希，非通用STEP解析器；全部文件统计与解析覆盖另列。

复验：下载上述固定原件到本机，执行`python scripts/verify_ifc_reference.py INPUT_IFC NEW_OUTPUT_DIR`。目录不覆盖。最终日志`public-final.log`，原始API与独立答案`public-final/`；约8.40秒包含隔离账号/项目/上传和解析，非纯内核基准，也不是并发性能验收。首轮直接子进程约5.67秒、输出约5.15 MB仅作本机观测。

浏览器已在获授权本机隔离项目真实上传，最终记录`cad_794d5f2037f24492bba67ac5792a284e`；源文件`file_419e9617fb2943ba8b269235d0a0a36d`。选择A102后显示来源关系Level 1 #39 / IfcRelAggregates #38297；声明面积30.14164524999992 m²与网格表面积109.86187 m²、体积71.39069 m³分列，不能互相替代。先前缺空间关系记录`cad_009c7ff3174049cc86a34bd3923db2d2`保留为stale。控制台无error。构件选择器避免在主界面展开整个多MB原始JSON；完整内容仍可下载。
