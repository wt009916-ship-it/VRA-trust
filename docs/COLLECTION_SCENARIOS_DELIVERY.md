# 多墙材料成本与碳方案交付（2026-11-08）

## 实际业务变化

之前的多墙材料计量只能给出同IFC材料实体去重后的包络量，不能直接进入材料方案比较。本批新增独立 `collectionscenario` 记录和 `/collection-scenarios` API，从已核验的多墙计量读取体积，按真实 `source_material_id` 映射两套材料方案，经过明确实体比例、采购损耗、密度换算后调用成本和碳清单计算。运输按去重材料采购质量及显式包装质量、比例、距离派生。前端可从材料计量打开表单、录入五阶段活动、保存、打开当前报告和JSON；历史与单墙方案分开。

没有将多墙材料伪装成单墙层ID，也不允许客户端修改来源体积。单墙协议保持原字段；共享计算逻辑抽取为上下文/映射类型，版本哈希包含新增模块，旧方案可能因规则变化保守失效，不改历史哈希。
