# 安全与高频操作验收 · 2026-10-30

范围：只攻击本轮隔离8910，未向正式8767或第三方系统施压。未启动模型API或EnergyPlus。以下不是渗透认证、生产容量承诺或企业级全项验收。

## 已修复

1. 开发者系统此前已在历史中公开。专用后台界面、数据库/账号/模型配置/身份管理接口、案例后台、专用备份接口及导入工具现保留本地并排除Git；公开构建不包含它们，普通用户登录/MFA/工程功能保留。历史清理需同时处理分支、标签和GitHub只读PR缓存。
2. 前端同一按钮重复进入缺少明确在途检查；新增忙碌锁。相同JSON写请求在途合并，独立在途写操作最多32项，不自动重试未知结果。
3. 应用缺少统一请求准入；新增单进程并发32、桶容量240/每秒120请求的上限，超限429及Retry-After。此全局保护不是按租户公平调度，也不能替代反向代理与网络层DDoS防护。

## 实际结果

- 私有模块拆分回归20通过，公开登录/工程针对性45通过。
- HTTP实际3500请求、并发30：200×1285、429×1215、404×250、403×500、400×250；5xx=0，攻击被接受=0；恢复200。p50约91.45ms、p95约146.79ms。首次脚本断言失败且服务日志未见对应5xx；禁止环境代理并先保存全量结果后复测通过，初次问题尚未完全归因。
- 真实浏览器：主题/侧栏/刷新各2500次DOM click，共7500次；另100次Playwright指针click。页面异常0、实际API请求1。DOM事件压力与真实指针事件分别计数，不称每个按钮均已测试。
- 单独验证3000个同体写调用：实际fetch一次，结束后锁释放允许下一次调用。准入下游异常也释放并发计数。

## 尚未验证/风险

- 未覆盖每一个按钮、所有表单和每种工程输入的千次操作；实际重计算任务的幂等、跨页面请求取消、多个用户同时编辑、大型3D/GPU内存、进程崩溃恢复和长时稳定性仍需继续测。
- 当前写合并仅当前浏览器同请求在途期间有效；服务端业务幂等键及多实例限流未实现。API参数化/CSRF/归属已有防护不等于所有攻击均安全。
- 私有集成用例在公开发行缺少附加模块时明确跳过；本机私有版另行验收。公开版契约不包含专用管理接口。
- 冷站校准、复杂高楼整模和真实工程覆盖的此前未通过项继续保留。

原始日志、首次失败和恢复包保存在本机隔离验收目录；不发布密钥、测试会话或私有源码。公网/生产压测尚未执行。
