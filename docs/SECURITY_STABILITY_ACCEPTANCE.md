# 安全与高频操作验收 · 2026-10-30

范围：只攻击本轮隔离8910，未向正式8767或第三方系统施压。未启动模型API或EnergyPlus。以下不是渗透认证、生产容量承诺或企业级全项验收。

## 已修复

1. 开发者系统此前已在历史中公开。专用后台界面、数据库/账号/模型配置/身份管理接口、案例后台、专用备份接口及导入工具现保留本地并排除Git；公开构建不包含它们，普通用户登录/MFA/工程功能保留。历史清理需同时处理分支、标签和GitHub只读PR缓存。
2. 前端同一按钮重复进入缺少明确在途检查；新增忙碌锁。相同JSON写请求在途合并，独立在途写操作最多32项，不自动重试未知结果。
3. 应用缺少统一请求准入；新增单进程并发32、桶容量240/每秒120请求的上限，超限429及Retry-After。此全局保护不是按租户公平调度，也不能替代反向代理与网络层DDoS防护。

## 尚未验证/风险

- 未覆盖每一个按钮、所有表单和每种工程输入的千次操作；实际重计算任务的幂等、跨页面请求取消、多个用户同时编辑、大型3D/GPU内存、进程崩溃恢复和长时稳定性仍需继续测。
