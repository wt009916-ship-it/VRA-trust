## 全阶段与交付门槛

1. 代码审计：完整目录、活动链、真/模拟/静态/占位/未完成、硬编码/空接口、公式单位异常、模型/API依赖及部署环境。README不证明实现。
2. 真实运行：隔离环境按安装说明启动，配置/数据库/API/日志可追溯；缺模型或密钥只能待验，环境修复先留失败；原始业务数据不变。
3. 工程独立复算：解析/Decimal等方法、原生参考输出、显式适用边界，不以模型解释代替。
4. 安全稳定性能：授权本机隔离账号、跨项目/CSRF/坏文件/注入；固定负载及资源竞争/故障恢复/长稳；不外部攻击或压测，不能以存活代替任务成功。
5. 验收回归：修改时专项；完整能力里程碑/发布前完整回归、同提交CI；未发布改动不计当前原型分。
6. 最终文件须逐项核对：项目功能清单.md；项目架构与技术审计.md；建筑专业盲测报告.md；工程计算交叉验证报告.md；AI Agent 能力测试报告.md；软件安全与稳定性报告.md；Bug 与缺陷清单.md；产品商业化成熟度评估.md；下一阶段开发优先级.md。另有第一阶段《项目能力初步审计报告》。分批交付报告不自动等于已完成这九份最终汇总。
7. 每个缺陷保留：编号、功能、描述、复现、预期、实际、严重度、证据、修复建议。关键严重项不能被高总分掩盖。
