## 实际方法和边界

候选先形成不可执行草案，再让同一模型对照原问题复核，只有最终计划能读取已授权记录；不扩工具、数据、计算权限或事件预算。同一模型复核不等于独立审查。干预同时包含互斥Schema和二次复核，因此不能把差异单独归因于“自我复核”或模型参数量。首轮Python JSON Schema单测通过，却不代表原生推理框架支持该Schema。

首轮混用了properties和oneOf/anyOf；llama.cpp官方说明明确列为不支持。修复仅展开完整互斥对象分支，未改变题目、答案、提示词、预算、模型。修复后16项脚本协议检查通过；它们不能当作真实模型理解能力。已达到淘汰条件，不再为该方法增加新的留出集或调提示词。

数值种子与Fraction/Decimal答案在frozen.json及fixture-preflight.json：热工总R=1.68、层R=1.5；碳五阶段合计3414kgCO₂e；4.5m悬臂2.8kN端荷载；施工预测第12天/偏差3天；7条设备样本、1缺失格、1时间缺口。均为明确合成参考数据，使用实际应用服务生成来源记录，再由真实模型完成计划/应用读取，不代表实楼校准。
