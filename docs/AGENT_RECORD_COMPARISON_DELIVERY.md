# Agent 跨记录比较交付

2026-11-15。新增当前已读事实的基准/对照比较工具，不用模型自由文字或模型提供的数字进行工程运算。当前限定热工构造、材料成本、声明边界阶段碳三类；复用已有计算记录，不重造热工或两材料方案计算器。该批是开发侧证据，不是原八维87场景全部重验。

## 已实现的完整任务

模型按用户问题选择字段，实际读两份同类记录，然后选择基准、对照、同一指标以及所需差值/相对变化。应用验证当前任务读取回执、字段选择和来源hash，重新调用原专业服务核验来源，用原始source_value进行50位Decimal计算。公式固定为“对照−基准”和“(对照−基准)/基准×100%”；只输出选定运算。零基准的相对变化保留null，绝对差仍可交付。

热工核对表面热阻及适用条件；成本核对币种、含税口径、地区、日期、声明功能范围和排除项；碳核对面积、年限、地域、方法、功能单位、阶段及替换边界、因子来源基准，同ID因子内容冲突另行拒绝。文字声明相同只说明声明口径相同，不证明两种材料/建筑真实等效。来源不完整或失效不能通过比较恢复数值。工程、运维、进度、能耗账等其他类型尚未接入本工具。

比较自动保存双方已核验的指定来源事实；任务最终答复及以后GET均依赖当前专业来源复核，旧来源或hash失效时当前卡片清空。原事件保留为历史快照。前端卡片标明基准、对照、差值方向、零分母和撤回状态；来源文字转义。浏览器仍按用户选择暂缓。

## 缺陷与限制清单

### ARC-01 / 中，已实现：缺少可核验跨记录派生交付

- 功能：J复杂拆解/多工具串联及A/C/H方案比较。
- 复现：要求给出两份当前记录同指标的基准差值；原来可以分别读事实，但没有通用正式比较工具。
- 预期：实际读回执→同口径检查→程序差值→当前来源撤回。
- 原实际：只能沿用单记录事实或自由文字，不足以证明完成差值任务。
- 证据：新增agent_comparisons、真实六题、after-project-change.json。
- 修复建议/本批处理：按明确来源和指标由应用计算，范围仍限定三专业。

### ARC-02 / 高，已修复待最终CI：重复来源被重复预留导致任务失败

- 功能：J工具调度与任务完成。
- 复现：两次thermal_read→professional_compare(finish=false)→对双方分别重复professional_deliver(false/true)。
- 预期：实际13事件可完成，最终来源每记录复核一次，仍不超过15。
- 实际：首轮C01七个事件后预检误报超预算，answer=null；没有伪装成功。
- 证据：live-first/C01-task.json及call-003.json；budget-fix.log；live-after-budget/C01-task.json。
- 修复建议/本批处理：additional_reads按各持久化记录唯一ID预留；实际调用仍逐项审计。不同记录测试仍预留不同复核。

### ARC-03 / 中，范围未全覆盖

- 功能：跨专业比较、复杂自由任务。
- 复现：比较结构安全、运维事件或能耗账，或者要求以U降幅推导全年节能。
- 预期：仅支持具备明确定义和足够来源的运算，不补造其他指标。
- 实际：本工具只支持热工/成本/碳相同指标，不能判性能等效、全年节能或安全。应用自动读取模式的输出计划仍是源字段交付，不会因文字提到比较而自动创建比较计划；未把完整问题覆盖判通过。
- 证据：Comparison类型、context检查、工具动态schema与task_completion仍为partial。
- 修复建议：未来需要专门的比较意图/范围契约及新增独立综合任务，不能把本六题推成整个Agent已可靠。

### ARC-04 / 待验证：真实界面交互

- 功能：结果卡、来源追溯和失效阅读。
- 复现：在浏览器完成完整比较任务并撤回来源。
- 预期：真实交互验证可读性、键盘和窄屏。
- 实际：只有函数/构建及真实HTTP，用户暂缓浏览器控制。
