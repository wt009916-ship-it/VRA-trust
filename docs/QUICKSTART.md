# 开始使用

适用版本：`feature/ai-building-workbench` 工程预览分支。以下为 Windows 本机流程，尚不包含公网或第二台电脑验收。

## 1. 安装和启动

准备 Python 3.12、Node.js 22.12+ 或 24、Git 和独立安装的 EnergyPlus 9.0.1。引擎须匹配，不应替换成较新版本后沿用旧验收结论。

```powershell
git clone --branch feature/ai-building-workbench https://github.com/wt009916-ship-it/VRA-trust.git
cd VRA-trust
./Setup.ps1
./Start.ps1 -Port 8767 -EnergyPlusPath 'C:/EnergyPlusV9-0-1/energyplus.exe'
```

替换引擎路径。`Setup.ps1` 创建 Python 环境、安装依赖，并在缺少构建时构建前端；首次源码安装需要联网，含本地 OCR 模型依赖。多个 Python 共存时，可指定 `./Setup.ps1 -PythonExe 'C:/路径/python.exe'`。源码更新后的构建步骤见 [开发说明](DEVELOPMENT.md)。

浏览器访问 http://127.0.0.1:8767/，保持启动终端运行。停止服务可在该终端按 Ctrl+C。脚本默认端口为 8766，上例显式使用 8767。已有自己的实例时直接打开原地址；另开实例须选择空闲端口并通过 `-DataDirectory` 使用独立数据目录。

首次创建管理员：新用户名 3–32 位、须包含字母；新密码 15–128 个字符，支持长口令、空格和中文，常见弱密码会被拒绝。没有默认账密，旧账号继续使用原凭据。后续成员默认凭管理员邀请注册。

## 2. 准备资料

可以先拖入文件，缺少内容后续补齐。提取出的项目用途、地点、面积等仍须人工核对。

|资料|当前用途|计算前要核对|
|---|---|---|
|IFC|读取可解析 IfcSpace、楼层及来源几何，形成候选|楼层、空间数量/面积、原点、边界和空调范围|
|DXF、矢量 PDF|读取适用的闭合轮廓、图层或图页|DXF 单位、PDF 米/point、层高、标高和遗漏|
|扫描 PDF、PNG/JPEG|OCR、框选标定、老图增强与有依据的原图补接|比例、自动/人工补接、遗漏空间与候选边界；补接不是已证实墙体|
|DWG|先从原软件导出 DXF|导出后单位、图层和边界是否保留|
|EPW|逐时天气质量检查与仿真输入|站点、年份、代表性、缺测/重复小时及项目适用性|
|检测报告、设备表、运行档案|保存并定位证据，供工程师登记参数|型号、批次、工况、单位、构造、时段和来源权限|
|账单/实测记录|作为项目补证资料保存|当前没有自动完成账单校准的闭环|

默认单文件上限64MB；IFC及模型输入预算2000空间，DXF/PDF闭合线环仍限100候选。没有IfcSpace时可显式启用墙板重建，生成有来源的INFERRED候选；源实体、范围或热边界不完整仍会阻断，上传成功不等于完整建模。源窗、楼层批量复核和设备CSV见[复杂建筑输入](COMPLEX_MODELING.md)。NASA POWER日数据用于气候背景分析，不能直接替代逐时EPW；Golden示例天气也不等于项目当地气象。

老图在「导入资料」选择「老旧图纸增强」，先框选并标定。识别记录可重新打开原图补接，新识别创建新任务。IFC内墙/洞口/楼梯/机电及源家具在独立「工程构件与室内」查看，几何并不自动成为热模型设备参数。四管制中央系统在「热工」内配置，可导入[设计JSON示例](../examples/central-system/README.md)。[完整操作及限制](INCOMPLETE_DRAWINGS_AND_SYSTEMS.md)。

## 3. 第一次演练

建议建一个明确标注「教学」的独立项目，使用 [两房间教学资料](../examples/building-workbench/README.md)：两个 5×8 m 房间，共 80 m²、层高 3 m，不对应客户建筑。

1. 从「导入项目资料」拖入 `synthetic-two-room.dxf`，核对提取字段和缺项后确认建项；也可手动创建面积 80 m² 的教学项目。
2. 在「建模工作区」使用本地几何解析，核对 DXF 单位和 `ROOMS` 图层。配套 PDF 比例为 0.05 米/point；不能把 PDF 比例直接填给 DXF。
3. 核对两个候选房间，在 2D/3D 中检查尺寸、层高、标高、空调和计面积属性，填写复核说明并保存。合并候选后仍须保存。
4. 在「热工」填写构造、窗墙比、负荷、温度、时段和参数来源。教学参数仅供演练；草稿可以缺项，计算准入不能跳过。
5. 演练可导入 `fixtures/demo/reference_5zone/weather.epw`，明确其 Golden 参考来源并复核；实际项目换成有依据的适用天气，不因选择该文件就成为当地气象。
6. 检查独立几何校验和计算准入；满足条件后「复核与发布」生成 IDF，再显式提交仿真。完成后核对 SQL/ERR、Warnings、输入版本与指标口径。
7. 在「工程复核」核对假设、未补资料和版本差异。交接时记录依据并导出问题包；接受情景不会补齐原件或解除计算阻断。详见[工程复核与交接](ENGINEERING_REVIEW.md)。
8. 在「材料与决策」登记有来源的候选，明确实际替换层、厚度、增量初始造价和约束，再比较和导出。没有费用依据时保留空值。

也可显式打开「探索参考项目」体验官方参考输入的计算流程。参考项目不是你上传的实际建筑。

## 4. 如何读取输出

- **候选 / 草稿**：可以修改、待复核，不构成工程确认。
- **核验通过**：该计算在声明输入及范围内通过检查；仍须复核适用性，不等于建筑精度或审查批准。
- **失败 / 结果不可用**：查看导入诊断、几何问题或 ERR，修复后生成新记录。
- **已失效 / STALE**：依赖输入或版本变化。先核对再重算；只改变碳因子时可单独重算碳派生结果。

报告为生成时快照。交付讨论时同时提供范围、来源、假设、运行 ID、待补资料和原始证据包。理想冷热需求、设备耗电、运行碳排与经济收益分别按对应口径阅读。

## 5. 账号与管理员入口

用户在「账号设置」管理密码、会话、MFA、恢复邮箱和企业身份；MFA 恢复码只显示一次，请自行安全保存。

管理员访问 `/admin`：

- 「账号与密码」：成员、邀请与访问管理。
- 「数据库管理」：业务记录、历史、完整备份与恢复演练。
- 「服务与身份连接」：AI/API、OIDC 和 SMTP。
- 「任务与审计」：队列和操作记录。

SSO、邮件找回须先配置服务；找回仅适用于已验证恢复邮箱，启用 MFA 时仍须第二因子。详见 [身份与恢复](IDENTITY_SECURITY_ACCEPTANCE.md)。原生密码管理器保存/填充/更新仍待人工复验。

## 6. 遇到阻断时

|现象|处理|
|---|---|
|DWG 无法直接解析|从授权 CAD 软件导出 DXF，核对单位与图层|
|PDF 候选面积异常|按原图已知尺寸重新标定，保留依据，检查图框和文字误识别|
|部分 IFC 空间不能解析|查看逐空间诊断，定位 GlobalId，修复源模型或明确分层范围；不能删失败空间冒充整楼|
|发布或运行被拒绝|处理缺项、面积、复核、边界和几何问题，不用默认假设掩盖未知项|
|助手说明失败|保留工具结果，查看时间线，按错误类型重试并避免重复计算|
|保存超时|先检查最新版本和任务，确认结果后再决定是否重试|
|管理员看不到历史项目|在后台核对无归属记录后显式恢复，不自动向其他成员开放|

运行目录默认为 `runtime/`，也可由部署者指定。完整备份包含数据库、原件、结果、检查点和私有配置；身份密钥恢复还须对应环境密钥或原 Windows 系统账号。不要公开原图、账单、数据库、账密或 Key。
