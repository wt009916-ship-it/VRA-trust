# IFC构件截面到受审梁分析交付候选

基于PR65/62047f9。新增实际IFC轮廓解析、对称非矩形截面计算、工程输入交付、表单和报告。产品尚未合并/发布；最终精确提交CI待验证。正式76、累计候选77暂保持，不能把专项通过当作95+或完整结构软件。

## 实际功能链

当前项目的IFC读取记录→明确选定IfcBeam/IfcBeamStandardCase→受隔离worker读取原件→截面参数及原始轮廓轴→人工选择X/Y弯曲轴并给出复核依据→用户明确提供跨度/模量/支承/荷载→既有恒定EI梁内核→同源JSON/HTML报告。

支持矩形、圆、锐角空心矩形、圆管、对称工字截面；工字根部圆角采用解析面积和一/二次矩积分，不能以外包矩形代替。米/毫米等按明确IFC单位转换，单项刚性/均匀缩放映射保留来源；旋转后的轮廓轴与世界坐标列示，用户须明确分析轴。提供面积、Ix/Iy、原始尺寸、实体/轮廓/映射ID和原件hash。

只取选定Body的明确恒定挤出轮廓。曲梁、斜挤出、开洞/添加凸体、多Body/多项、非均匀/反射映射、不支持的轮廓、翼缘斜率/外缘圆角和空心矩形圆角保持unsupported；不猜测矩形或净截面。实体挤出长度单列，绝不自动填跨度；材料名、空间接触不用于猜模量、支承或荷载。缺参计算仍incomplete/null。输出不含强度、屈曲、连接、动力、承载力或结构安全判定。

来源记录和计算均保留不可变快照，写事务内重新核验源记录/项目/原件；跨项目/账号、CSRF及伪造actor受拒。actor从实际会话取得，人工复核不使模型几何变为实测。项目、原件、依据或算法改变撤下当前计算，历史保持。新辅助模块纳入版本哈希；共享来源组件和解析运行时变化会使相关历史记录保守失效，不能通过重写历史hash解除。正式业务数据未改。

## 真实公开文件及独立计算

固定buildingSMART Community Sample Test Files提交31eb1dd0a0406fb9ebf0ebd823b48e1ec95afc08的四份ISO示例：beam-extruded-solid、beam-revolved-solid、beam-varying-profiles、beam-varying-extrusion-paths。原始文件署名Jon Mirtschin (GeometryGym)与Tim Chipman (Constructivity)。上游索引和获取hash见public-acquisition.json；未确认原件再分发许可，原件留在本机C盘，Git仅归档输入索引和实际提取/计算结果。

注意varying-profiles文件是不同梁具有不同等截面，不是同一梁沿长度变截面；因此按实际STEP实体而不是文件名决定结果。六个选定构件4个提取成功、2个旋转实体明确不支持。实际HTTP输入原件逐字节保留，所有39项最终检查成功，30次响应，测试服务已关闭。

实现前冻结IPE600参考：b=0.22m，h=0.6m，tw=0.012m，tf=0.019m，根圆角r=0.024m。独立128点Gauss–Legendre角度积分与分区矩形求和，非产品解析式，得A=0.015598442631532275m²、Ix=0.0009208345717756825m⁴、Iy=0.00003387342477398636m⁴；预定相对容差1e-10。冻结文件SHA256为543b8e3bdd851e707deb55715f523ab17a451d2623e07f5e5033790d3fde511d。

真实HTTP示例明确另行假设8m支承跨度、210GPa模量和中点10kN集中力；这些不是公开模型提供的实测力学数据。独立闭式解P L³/(48EI)与实际挠度0.0005516045156265509m一致；左右反力各5000N、最大弯矩20000N·m。撤回这份力学假设后，当前result=null且新计算被拒。不是建筑安全验收。
