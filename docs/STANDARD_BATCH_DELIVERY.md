# 多规范精确查询交付与真实Agent失败记录

本批补齐原总账F05中的多规范/多条款明确配对查询。输入1–8条规范编号、可选版次与精确条款，同一批共用一次资料目录读取，各项保留已找到、未找到、版本冲突及排除原因。单条/关键词查询兼容，原有含多个自由文本编号的歧义请求仍拒绝，不能悄悄选择其中一个。查询多条不等于已实现跨规范法律适用性推理。

前端新增多条款对照；同号条款按各自规范定位，缺失项保留。可见查询每5秒重新核验，4秒超时、断网、隐藏状态撤下引文；迟到响应不能覆盖新查询。重新复核资料不会让旧查询复活。保存JSON保留旧快照，GET当前结果失效时返回null。

Agent的standards_search支持同一批量契约。实际成功查询的引文通过当前目录摘要、检索器摘要及事件结果完整性核验后才显示；历史任务重新读取时撤下失效引用。模型原文不作为引文或合规结论。Agent卡片当前性在任务读取时重验，本批未证明已展示Agent卡片自动后台刷新；规范工作区的5秒轮询已实际验收。框架执行成功仍不等于用户任务完整完成。
