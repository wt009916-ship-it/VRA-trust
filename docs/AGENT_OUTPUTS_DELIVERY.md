# Agent 指标与解释交付批次

## 实际变化与边界

指定记录的复合读取过去可以交付部分指标，却遗漏所问总R或解释。本批默认先让模型从原问题选择所需指标/解释主题并冻结计划，再读取声明范围、逐项核验。应用用当前来源生成说明，来源或解释契约变化后撤下旧说明；模型不能通过资料名称改写计划。已经交付的数值工具从后续候选中移除，尚未交付的要求保留。

计划仍是模型理解，intent_verified=false；计划完成不能证明自由问题全部完成。模型自由正文不转成工程结论。没有新工程计算、没有扩大计算或读取权限、没有模型训练。infer_outputs默认true，仅对显式read_requests生效；旧协议可显式false，旧记录不强行生成历史计划。六类专业记录支持有限解释主题，不能据此认定开放问答通用可靠。
