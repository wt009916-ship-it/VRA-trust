# 开放专业任务与结构化说明核验

本批把自然语言提问接到已有热工、阶段碳和材料成本记录：模型选择专业、查找记录、读取并提交事实，应用重新核对数值、单位、期间及面积分母。新增 `professional_deliver`，工具共31项。不是新计算器、训练模型、工程认证或全任务自动完成系统。开发复评保持73分，不能把限定测试通过率当作产品总分。

## 调用链与使用边界

选择“自由提问”和真实模型模式即可执行；无需预先指定这三个专业目标。流程只先读取项目，专业列表、记录及交付由模型选择；最终读取由控制流程执行，两种来源继续单独记载。没有专业交付时返回 `open_task_unverified / not_assessed`，不再把能耗IDF/EPW准入当成热工、造价或结构任务结论。“本地工程流程”没有模型，不会自动解析自由问题，仍可选择明确核验目标。

已有列表、显式记录ID和历史引用构成读取工具的ID选项；交付工具在读取后才提供已读取ID和hash选项。这些是模型提示和参数约束，运行时仍独立检查项目归属、实际读取记录、当前hash和来源状态，不依赖模型遵守提示。历史只带记录引用，不能代替重新读取。最多三个不同记录，仍受5轮模型、每轮至多4调用和15事件总预算约束；并不保证任意三个记录任务都能在预算内完成。

`Delivery`绑定kind、record_id、record_hash与1–12条不同事实。每条事实明确value、unit、period、study_years、area_m2；不适用的口径也必须显式null。核验对象为总R、层R、U、阶段碳总量/单位面积量/纳入阶段量及材料清单总金额。没有的节能率、排除阶段零排放、安全认证、碳信用不能作为事实交付。碳阶段量均按整个评估期，不能把年活动量的计算结果再标成年度排放。货币十进制字符串保持精确；浮点工程量采用已声明的12位有效数字显示口径，同时保留source_value原值，不用宽松误差阈值接收任意舍入。

单位、数值或期间错误返回具体纠正字段，最多两次读取/参数恢复，原失败事件保留。最后一份交付可由模型标记 `finish=true`，只有本批调用全部通过才结束模型循环，随后仍读取当前记录核验；不增加预算，不让失败交付用finish强制结束。另以实际旧协调器与旧语义模块执行五轮协议回放：第五轮成功交付后，旧版因还需结束轮次而failed；新版保持5次模型请求、12个事件并交付partial，见finish-replay.json。这个对照是协议夹具，不算真实模型题。正式回答是 `partial`：所列事实经过核验，自由问题的完整覆盖尚未评估。相同记录再次交付会替换本任务先前选择，不能用多个重复记录虚增完成量。

完整工具输出留在审计事件里。发送给模型的专业结果明确标为事实投影，保留ID/hash/来源状态/范围/事实及定位；不隐瞒它省略了完整输入。成功交付只回传接受的字段标识，避免把同一组事实重复塞入上下文。完整逐项计算、因子、原单位、边界与报告仍由正式结果卡呈现。模型自由文字保留在认证后的任务API审计数据中，不作为工程说明；这不证明模型理解、解释或整个复杂任务正确。

查看历史任务时重新核验当前专业记录。来源、项目或计算版本变化后，旧正式数值隐藏、状态变为incomplete，原任务记录及工具时间线不覆盖。专业核验不自动创建新热工/碳/成本记录；其他专业工具仍可调用，但尚未接入此事实交付协议，不能宣称所有开放任务已支持。
