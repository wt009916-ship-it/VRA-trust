2026-11-08。基于已同步的73ac1cf继续完成同一Agent里程碑；没有扩大训练或开展整体视觉改版。开发侧77/100保持。

用户现在可以在同一声明任务中读取指定热工结果、核验指定造价记录缺失、检查另一专业记录可用性；即使最后一个模型响应没有finish标志，已提交内容仍会进行最终来源核验。未提交目标继续标为未完成，不把控制流程结束当成自由问题全部完成。

## 实现及边界

- 声明读取目标提供基于真实读取状态的下一动作。未知目标先读；实际读取失败才向模型提供缺失交付；失效目标提示professional_limit；正式缺失和已核验可用性不再反复提供相同读取入口。
- 五轮模型预算耗尽时，声明读取任务进入有类型的结束状态，使用预留事件复核已提交收据。仍为5轮/15事件，不增加写权限、不自动执行建议、不把尚未提交的目标补成成功。
- 自由原文中的专业记录编号与声明清单精确比对，包括长度错误。错误原文留在事件审计，在剩余轮次请求模型修正；无法修正时保留原文并显示错误提示，不静默替换编号。此检查不验证数值解释、区域对应、因果或规范语义。
- 前端显示轮次上限与逐项状态。实际audit_only路径也显示引用错误提示，原文不作为工程结果。
