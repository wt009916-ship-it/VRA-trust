# Data Truth Rules
EnergyPlus supplies energy; SQL supplies units/locators. LLM cannot invent EUI/carbon/savings/success.
DEMO_MODE=false by default. Historical result JSON is never served by production. Explicit reference input may run EnergyPlus with engineering_reference labels.
Provenance: run_id/project_id/case_id/scheme_id/model_hash/weather_hash/engine_version/code_version/parser_version/factor_version/timestamp.
Fail closed on engine/SQL/ERR/unit/version/evidence/binding/stale/hash errors.
Operating CO2 ≠ lifecycle emissions ≠ issued credits. No measured rare-earth parameters or calibrated sensor means no measured-performance claim.
Only exhaustive finite coverage or verifiable bounds prove stability. Until tested robustness exists, report not_assessed and refuse a definite winner.
