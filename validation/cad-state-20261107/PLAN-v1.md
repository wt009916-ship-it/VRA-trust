# CAD 当前状态刷新计划

前置：完成 PR51 的六项CI、合并和本机发布。当前未完成95+；开发复评77须以发布回执确认。

IFCU-06 已真实复现：隔离合成原件损坏后，cad-inspections GET为stale/null，新并集卡已撤下，旧构件明细仍显示24m³。baseline-v1.json、browser-legacy-stale-v1.log与baseline-stale.png为证；测试原件已恢复。

实施：
1. 增加有界、只返回状态与来源标识的 CAD 当前性接口，复用项目归属、记录完整性、文件哈希和解析器版本核查；不返回整份几何结果，不修改历史。避免每5秒传输所有大型CAD JSON。
2. 页面只轮询当前显示记录，控制并发；失效即清除旧数量、构件选择详情及相关下载说明，展示原因和重新读取入口。网络失败不能保留看似当前的量。新并集工作区继续保持已验证的失效逻辑。
3. 状态恢复或新读取时按当前API重新取详情，禁止把缓存改状态后重新当有效结果。只更新受影响记录，避免打断用户多选/操作。
4. 处理迟到响应、页面切换和重绘时的任务取消；旧parsed响应不能覆盖新stale状态。标明最近核验时间，避免暗示持续实时保证。
5. 独立API安全测试：匿名、跨账号、跨项目、篡改记录、源文件损坏、解析器版本变化、预算、只读记录数不变。浏览器重放baseline，并做真实响应延迟/断网、390px截图和恢复。
6. 全量回归、同字节Git构建、证据/复评与GitHub同步。不得删除旧origin缓存引用；当前C仓库主线对象正常，必要时针对GitHub已确认提交校验父与树后只更新github/main。

后续仍需材料归属/专业计量规则、Agent一般注入及长稳；训练和整体视觉改造按用户顺序后置。
