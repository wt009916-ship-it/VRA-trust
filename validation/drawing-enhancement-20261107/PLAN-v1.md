# 下一批：图纸处理版本、坐标追溯和尺度冲突

2026-11-07，准备阶段，尚未实现或运行本批测试，不计分。前一批设计负荷 PR #45 尚在等待远端后端检查；本计划不修改其已冻结应用源码或证据。用户顺序仍为能力95+、再扩大训练、最后整体前端优化；当前设计负荷开发复评76，发布状态另看回执。

## 已核查的现状

活动代码 backend/drawings.py、drawing_worker.py、drawing_models.py。现有PNG/JPEG/PDF单页解码、EXIF方向/白底规范化、RapidOCR候选、原件/预览摘要、人工更正和版本失效；OCR分数不是正确概率。已有合成七图和Kinnear选定标签验收，不能再作为未见样本。尚无工程比例尺校验、倾斜处理版本、去噪比较、墙线修复、缺失尺寸推断、构件分类或跨图关联。

## 范围与顺序

1. 先实现来源保全的明确旋转/处理版本及可逆像素坐标变换；每份派生件独立ID、原件hash、页号、尺寸、参数、算法版本、变换矩阵、改变说明和输出hash。既有原件和OCR记录不覆盖，原图/处理图对照。不会把补白、插值或过滤结果叫作恢复出的真实工程信息。
2. 再实现用户明确标定的两点长度/单位及多标定一致性检查。像素、PDF光栅dpi和工程长度分离；缺尺寸不给工程长度。工程尺度属于明确声明，不能把人工输入升级为测绘事实。校准必须绑定同源页和变换版本，跨图/跨页/过期不可套用。
3. 去噪和自动倾斜建议需先建立独立金标准，再决定是否进入产品；弱线丢失必须计为失败或限制，不通过改变测试阈值宣称修复。默认不补墙线、不补缺失结构或尺寸，不自动写入热工/结构/BIM参数。

## 先冻结的验证规则

- 新合成输入先记录所有线段、门窗符号、文字与尺寸的位置及随机种子，再生成退化；不从算法输出生成答案。新增一张有明确授权来源的公开图，仅预标可判读的区域；保留未判读部分，不能报整图准确率。已有Kinnear只作历史回归。
- 坐标基准包含0、+7、−7度、靠四边角/中心/文字框的点。纯矩阵正逆映射误差必须≤1e−6像素；图像插值误差另记，不能拿矩阵正确代替图像语义正确。处理边界扩展、补白及裁切规则在执行前固定。
- 源/派生图的SHA和字节分别核验，OCR框明确绑定当前预览坐标；若映射回原图，保存映射依据。修改源、参数、预览或算法版本后已有标定/当前结果必须失效，不重写旧记录消除失效。
- 标定例：100像素=6000 mm，与50像素=3 m等价，单位换算由独立有理数手算；100像素=6000 mm且同范围50像素=4 m存在冲突，不得平均后当作有效尺度。零长度、重合点、负值、NaN/Inf、未知单位、越界点、不同页/来源与欠缺参数均拒绝。
- 一致性公差与用户声明的量测不确定性需先定义，不能将工程容许误差凭空称作规范值。非等比扫描不得用一个标定值宣称全图两轴均准确；未知畸变显式保留。
- 去噪金标准包含1像素/2像素弱线、局部缺失、污点与重叠；分别记录新删除和新增加的线像素及未恢复缺口。任何自动生成的线条都不能冒充原始构件。图像视觉改善不等于尺寸/结构正确。
- API/实际子进程/JSON/预览下载/浏览器及跨项目权限、CSRF、尺寸预算、畸形文件、并发修订和历史失效必须在限定功能中真实验证。私有隔离目录，不用原型数据库跑试验。
- 阶段结论区分实现、独立合成验证、公开样本子集、真实建筑专业验收；没有完成的列待验证。只在新增专业证据满足原评分子项后复评，不按新增测试数量加分。
