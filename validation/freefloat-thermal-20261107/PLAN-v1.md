# 下一批：自由漂移温度独立基准（预先计划）

在PR47等待远端CI期间只准备独立探针，不修改该PR应用源码或其已冻结证据。PR47仍需合并和原型发布收尾。沿用原八维95+目标；当前76分。

上一批墙体解析解夹定室温，不能证明室温动态正确。本批先使用均质无热容量围护、固定内外膜系数、已知房间体积和空气热容量倍率，停用空调，以独立能量守恒验证温度动态。明确这是受控合成研究算例，不把热容量倍率当真实建筑校准。

采用 C(T)dT/dt=UA(T外−T)+Q，C(T)=S/(T+273.15)，S=V·倍率·p·cp/[287(1+1.6077687w)]。压力101325 Pa；极干设计气象使原生空气物性使用w下限1e-5，该物性前提必须用实际输出/固定源码核实。无内热时每个常值外温步可用logistic封闭解；非零对流内热以T平衡=T外+Q/UA处理。该独立解不复刻EnergyPlus的离散求解器，也不读取原生温度作为答案。

先固定温度容差0.02 K、输入日程、初值/周期稳定判据和1/5/10分钟步长，再运行原生引擎。检验恒温边界、周期边界、纯对流内热、热容量变化、至少两个原生空气求解器及时间步敏感性。优先核对空气物性、边界与小时平均定义；任何失败保留，不调宽容差掩盖。

只有限定基准达成后，才继续讨论用户界面中的逐时温度选择、工况/资料适用性提醒及评分。公开/合成参考不能替代实楼测温、太阳/通风/潜热耦合、完整设计与专家验收。跨平台复算必须使用逐字节相同冻结输入及答案。
