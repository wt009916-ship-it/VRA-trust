# 合成教学资料

两个相邻 5 × 8 m 房间，总面积 80 m²，层高 3 m；不对应客户建筑。

- DXF：ROOMS 图层，文件单位毫米，可自动读取。
- PDF：一页矢量平面，换算系数填写 **0.05 米/point**。
- IFC：已导出的两个 IfcSpace，可导入回读。
- model-draft.json：未复核的教学参数与构造，可供 API 开发者阅读；不能作为现场参数。

建立明确标注“教学”的独立项目演练。热工面板的教学按钮使用相同假设。所有候选仍需填写复核说明。真实项目应改用其授权文件、参数和当地 EPW。官方 Golden EPW 在 fixtures/demo/reference_5zone；只适用于参考演练，不是项目所在地天气。
